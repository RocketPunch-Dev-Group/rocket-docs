## 스레드 작성

오늘의 생각, 일에 대한 통찰, 커리어 궁금증 등 간단한 게시물을 작성할 수 있습니다. 이미지 등 파일을 첨부하거나 이모지, 링크(URL)를 넣을 수도 있습니다.

프로필 전환을 통해 기업 프로필로도 스레드를 작성할 수 있습니다. 단, 프로필을 중복해서 선택할 수는 없습니다.

| 항목 | 내용 |
| --- | --- |
| 글자 수 | 공백을 포함해 최대 2,000자까지 쓸 수 있습니다. |
| 서식 | 일반 텍스트로만 저장됩니다. 굵게, 기울임 같은 서식은 지원하지 않습니다. |
| 줄 바꿈 | 줄 바꿈은 연속 입력할 수 없습니다. 게시하면 빈 줄은 한 줄까지만 남고, 게시물의 맨 첫 줄은 비울 수 없습니다. |

## 스레드에 첨부할 수 있는 항목

### 이미지 첨부

한 게시물에 최대 10장, 전체 100MB까지의 이미지를 업로드할 수 있습니다. JPG, JPEG, PNG, WEBP, GIF 형식을 지원합니다.

### 투표

하나의 게시물에 투표를 하나 첨부해 다른 사용자의 의견을 받을 수 있습니다.

| 항목 | 내용 |
| --- | --- |
| 구성 | 질문 1개와 선택지로 이루어집니다. 질문과 각 선택지는 1~30자까지 입력할 수 있으며, 특수문자도 사용할 수 있습니다. |
| 선택지 개수 | 기본 2개이며, 최대 4개까지 추가할 수 있습니다. |
| 참여 방식 | 한 사람은 한 선택지에만 투표할 수 있고, 중복 선택은 할 수 없습니다. |
| 투표 기한 | 게시물을 올린 시점부터 투표가 가능하며, 게시물이 삭제되면 자동 종료됩니다. |
| 수정 제한 | 게시물을 올리기 전에는 투표를 수정하거나 삭제할 수 있지만, 올린 뒤에는 투표를 수정할 수 없습니다. |

### 링크 미리보기

본문에 링크(URL)를 입력하면 미리보기 카드가 함께 표시됩니다. 링크를 여러 개 입력해도 가장 먼저 입력한 하나만 카드로 표시됩니다.

### 리포스트

다른 게시물을 원문 그대로 담아 내 피드에 다시 올릴 수 있습니다. 리포스트할 때 내 글을 함께 작성할 수 있습니다.

| 항목 | 내용 |
| --- | --- |
| 리포스트 횟수 | 같은 게시물은 한 번만 리포스트할 수 있습니다. |
| 리포스트 취소 | 원본 게시물에서 리포스트 버튼을 다시 누르면 취소할 수 있고, 취소 시 리포스트로 올렸던 게시물은 즉시 삭제됩니다. |
| 원본이 삭제 · 숨김된 경우 | 리포스트한 원본이 삭제되거나 숨김 처리되면, 리포스트 게시물에 "이 글은 더 이상 볼 수 없습니다. / 글이 삭제되거나 숨겨졌습니다."라고 표시됩니다. |

#### 스레드 리포스트

원본 스레드에 내 글을 함께 작성하여 리포스트할 수 있습니다.

#### 디스커버 리포스트

리포스트 제목과 내용 일부, 썸네일에 내 글을 함께 작성하여 리포스트할 수 있습니다.

## 스레드 수정과 삭제

스레드의 `더보기 버튼 ⋮` 을 누르고 스레드를 수정하거나 삭제할 수 있습니다. 스레드 수정 시 본문은 수정 가능하지만 이미지는 수정이 불가합니다.
