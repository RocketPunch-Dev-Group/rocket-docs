## 부적절한 프로필 신고하기

부적절한 프로필을 발견하면 신고할 수 있습니다. [커뮤니티 가이드라인](https://www.rocketpunch.com/terms?termType=COMMUNITY_GUIDELINE)을 지키지 않거나 법적 · 윤리적으로 문제가 있다고 판단되는 프로필을 신고해 주세요.

1. 신고할 사용자의 프로필에서 더보기 버튼 `···` 을 누르고 `신고하기`를 클릭합니다.
2. 신고 사유를 선택하고 `제출` 을 누릅니다.
   | 신고 사유 | 설명 |
   | --- | --- |
   | 학력, 경력, 자격 등 사실과 다른 정보 기재 | 재직한 적 없는 회사를 경력에 넣거나 취득하지 않은 학위 · 자격증을 올린 경우입니다. |
   | 타인의 이름, 사진, 경력을 도용한 계정 | 다른 사람인 것처럼 꾸며 활동하는 사칭 계정인 경우입니다. |
   | 만 15세 미만의 사용자로 보이는 계정 | 서비스 이용약관에서 정한 최소 가입 연령에 미치지 못하는 것으로 보이는 경우입니다. |
   | 자기 소개 등에서 차별적 언행 포함 | 인종, 성별, 종교 등을 이유로 특정 집단이나 사람을 비하하는 표현이 담긴 경우입니다. |
   | 자유 입력(최대 500자) | 위 사유에 해당하지 않는 내용을 500자 이내로 직접 입력합니다. |
3. 신고한 프로필은 내 화면에서 바로 숨겨지고, 접수된 신고는 운영팀의 내부 검토를 거쳐 처리됩니다.

## 차단하기

특정 사용자나 기업을 차단할 수 있습니다. 상대의 프로필, 상대가 쓴 게시물 · 댓글에서 더보기 버튼 `···` 을 누르고 `프로필 차단` 을 누르면 차단할 수 있습니다.

차단하면 이렇게 바뀝니다.

- 피드에서 상대의 콘텐츠를 추천하지 않습니다.
- 상대의 활동 알림을 받지 않습니다.
- 팔로우 중이었다면 팔로우가 해제됩니다.
- 서로 메시지를 주고받을 수 없습니다.

## 차단 해제하기

`설정 > 차단한 프로필` 에서 차단한 사용자를 확인하고 해제할 수 있습니다.

## 채팅 신고하기

부적절한 메시지를 받았다면 신고할 수 있습니다. [커뮤니티 가이드라인](https://www.rocketpunch.com/terms?termType=COMMUNITY_GUIDELINE)을 준수하지 않거나 법적 및 윤리적으로 문제가 있다고 판단되는 메시지를 신고해 주세요.

1. 신고할 메시지를 마우스 우클릭하거나, 모바일에서는 길게 눌러 `사용자 신고`를 선택합니다.
2. 신고 사유를 선택하고 `제출` 을 누릅니다.
   | 신고 사유 | 설명 |
   | --- | --- |
   | 타인에 대한 모욕적 표현 | 욕설이나 비방, 조롱으로 상대를 깎아내리는 메시지를 받은 경우입니다. |
   | 송금 요구나 피싱 링크 유도 등 | 투자나 대출을 빌미로 송금을 요구하거나, 개인정보를 빼내려는 링크를 보내는 경우입니다. |
   | 대량 발송이나 무관한 광고 메시지 | 대화 맥락과 관계없는 홍보성 메시지를 반복해서 받는 경우입니다. |
   | 불쾌하거나 선정적인 언어나 이미지 포함 | 성적 수치심을 유발하는 표현이나 이미지를 받은 경우입니다. |
   | 자유 입력(최대 500자) | 위 사유에 해당하지 않는 내용을 500자 이내로 직접 입력합니다. |
3. 신고한 메시지는 내 화면에서 바로 숨겨지고, 접수된 신고는 운영팀의 내부 검토를 거쳐 처리됩니다.

<Note>
  신고는 익명으로 유지되며, 제출 후 더 이상 추천되지 않습니다. 상황이 심각한 경우 현지 기관으로 추가 신고하시기 바랍니다.
</Note>
