로켓펀치 Open API는 채용공고 · 이벤트 · 게시글 등의 데이터를 조회하고 연동할 수 있는 REST API입니다. App Key를 한 번 발급받으면 바로 호출할 수 있고, 사용자를 대신해 글을 쓰는 것처럼 권한이 필요한 작업은 OAuth 2.0으로 동의를 받아 처리합니다.

## 먼저 알아두실 것 — 주소가 세 개입니다

역할이 다른 세 개의 주소를 사용합니다. 헷갈리기 쉬운 부분이라 먼저 정리해 드릴게요.

| 주소 | 역할 | 언제 쓰나요 |
| --- | --- | --- |
| `openapi.rocketpunch.com` | **API 서버** | 실제 데이터를 호출할 때. `/api/v1/...` 요청과 토큰 발급(`/oauth/token`)을 보냅니다. |
| `developers.rocketpunch.com` | **개발자 콘솔** | 앱을 등록하고 App Key를 발급 · 관리할 때. 사용자 동의 화면(`/oauth/authorize`)도 이곳입니다. |
| `docs.rocketpunch.com` | **문서** | 지금 보고 계신 이 문서입니다. |

<Warning>
  토큰 발급(`/oauth/token`)은 API 서버, 사용자 동의(`/oauth/authorize`)는 개발자 콘솔입니다. 두 주소가 서로 다르니 연동할 때 주의해 주세요.
</Warning>

## 두 가지 인증 방식

무엇을 하려는지에 따라 인증 방식이 달라집니다.

| | App Key | OAuth 2.0 |
| --- | --- | --- |
| 헤더 | `X-RP-API-Key` | `Authorization: Bearer` |
| 사용자 로그인 | 필요 없음 | 필요 |
| 할 수 있는 일 | 공개 데이터 조회 | 사용자를 대신한 작성 · 수정 · 삭제 |
| 예시 | 채용공고 검색, 이벤트 목록 | 게시글 작성, 내 회사 권한 조회 |

각 API가 어떤 인증을 요구하는지는 API 레퍼런스의 `security` 항목에서 확인할 수 있습니다.
