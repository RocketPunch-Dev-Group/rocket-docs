## 네트워크

로켓펀치 월렛에는 주요 네트워크가 기본으로 등록되어 있습니다. `월렛` \> `더보기 버튼 ☰` \> `네트워크 연결` 에서 등록된 네트워크를 확인할 수 있습니다.

## 커스텀 네트워크 추가하기

기본 목록에 없는 네트워크는 직접 추가할 수 있습니다. `월렛` \> `더보기 버튼 ☰` \> `네트워크 연결` \> `커스텀 네트워크 추가` 에서 다음 정보를 입력합니다.

| 항목 | 내용 |
| --- | --- |
| Network Name | 네트워크 이름입니다. |
| RPC URL | 네트워크에 연결할 주소입니다. 여러 개를 등록할 수 있습니다. |
| Chain ID | 네트워크를 구분하는 고유 번호입니다. |
| Currency Symbol | 해당 네트워크의 기본 화폐 기호입니다. Ethereum이라면 ETH가 여기에 해당합니다. |
| Block Explorer URL | 거래 내역을 조회할 수 있는 사이트 주소입니다. 선택 항목이며 여러 개를 등록할 수 있습니다. |

추가한 네트워크는 커스텀 네트워크로 따로 표시되며, 목록에서 삭제할 수 있습니다.

<Warning>
  네트워크 정보를 정확히 입력해야 합니다. 잘못된 정보를 넣으면 전송이 실패하거나 자산을 잃을 수 있습니다. 네트워크를 만든 곳이 공식적으로 안내하는 값만 사용하시기 바랍니다.
</Warning>

## 토큰

자산 목록에는 기본적으로 일부 인기 토큰만 표시됩니다. 목록에 보이지 않는 토큰은 직접 추가해서 불러올 수 있습니다.

`월렛` \> `더보기 버튼 ☰` \> `토큰 불러오기` 에서 불러온 토큰을 확인하고, `커스텀 토큰 추가` 로 새 토큰을 추가합니다. 먼저 네트워크를 선택한 다음, 이름으로 검색하거나 직접 입력해 추가합니다.

직접 입력하여 추가 시 다음 정보를 입력합니다.

| 항목 | 내용 |
| --- | --- |
| 토큰 컨트랙트 주소 | 네트워크에서 해당 토큰을 식별하는 주소입니다. 이름이 같아도 컨트랙트 주소가 다르면 다른 토큰입니다. |
| 토큰 심볼 | 자산 목록에 표시되는 약칭입니다. USD Coin이라면 USDC가 여기에 해당합니다. |
| 토큰 이름 | 토큰의 정식 이름입니다. USDC라면 USD Coin이 여기에 해당합니다. |
| 소수점 자릿수 | 토큰을 나눌 수 있는 최소 단위입니다. 토큰을 발행할 때 정해진 값을 그대로 입력합니다. |

### 스캠(사기) 토큰 주의

토큰을 직접 추가할 때는 아래 내용을 확인하고 동의해야 합니다.

<Warning>
  **이름이 아니라 컨트랙트 주소로 확인하세요.** 토큰은 누구나 발행할 수 있고 이름도 원하는 대로 지을 수 있어서, 유명 토큰으로 위장한 악성 토큰이 많습니다. Etherscan, BscScan, Polygonscan 같은 탐색기에서 원하는 토큰을 검색하면 정확한 컨트랙트 주소를 확인할 수 있습니다.

  **모르는 사이에 들어온 토큰을 주의하세요.** 월렛 주소만 알면 누구나 토큰을 보낼 수 있습니다. 프로젝트가 관심을 끌기 위해 여러 월렛에 토큰을 무상으로 보내는 것을 에어드랍이라고 하는데, 정상적으로 쓰이기도 하지만 가치 없는 토큰에 관심을 만들거나 피싱에 이용되기도 합니다.

  **비밀복구구문을 요구하면 사기입니다.** 스캠 토큰은 다른 토큰으로 환전하지 못하도록 막아두고, 대신 개인정보나 비밀복구구문을 입력하라고 요구합니다. 비밀복구구문이 유출되면 월렛의 모든 자산을 잃을 수 있습니다.
</Warning>

불러온 토큰은 자산 목록에 표시되며, [보내기](/wallet-send) 와 [받기](/wallet-recieve) 에서도 선택할 수 있습니다.
