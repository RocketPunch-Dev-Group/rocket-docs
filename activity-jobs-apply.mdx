설정에서 지금까지 지원한 채용공고를 모아 볼 수 있습니다. 

- 채용 간편 지원: 로켓펀치에서 바로 지원한 공고입니다. 전형 진행 상태가 함께 표시됩니다.
- 외부 웹사이트 지원: 기업의 자체 채용 페이지로 이동해 지원한 공고입니다. 

## 진행 상태 확인

내역마다 기업명, 공고명, 지원일과 현재 진행 상태가 표시됩니다. 상태별로 나눠 보려면 목록 위의 필터를 사용합니다.

| 필터 | 내용 |

| 전체 | 지원한 모든 공고입니다. |
| 진행 중 |  |
| 최종 합격 |  |
| 채용 중단 |  |

진행 상태는 기업이 전형을 진행하면서 갱신합니다. 

<Tip>
  제출한 서류
</Tip>

지원할 때 등록한 이력서, 포트폴리오, 자기소개서, 기타 서류는 프로필의 라이브러리에 자동으로 추가됩니다. 다음 지원에서는 다시 올리지 않고 등록된 서류를 선택할 수 있습니다.

이미 지원한 공고에는 다시 지원할 수 없습니다. 삭제되거나 비공개로 바뀐 공고, 모집이 끝난 공고도 지원 화면으로 들어갈 수 없습니다.

### 간편 지원 내역 확인하기

`설정 > 채용 간편 지원` 에서 공고와 진행 상태를 한 눈에 확인할 수 있습니다. 각각의 지원 내역을 열면 지원 시 제출한 정보와 현재 진행 상태를 볼 수 있습니다.

- **지원 취소:** 진행 중인 지원은 `지원 취소하기`로 취소할 수 있습니다. 취소하면 상태가 `지원 취소`로 바뀝니다.
- **내역 삭제:** 기업이 오랜 기간 상태를 업데이트하지 않아 전형이 자동으로 종료된 지원은 `지원 내역 삭제`로 목록에서 지울 수 있습니다.

## 지원 페이지로 이동하여 지원하기

기업이 지정한 외부 채용 페이지에서 지원하는 방식입니다. `지원 페이지로 이동`을 누른 뒤, 이동한 사이트의 안내에 따라 지원을 완료합니다.

### 외부 웹사이트 지원 내역 확인하기

`설정 > 외부 웹사이트 이동 > 채용 공고` 에서 확인할 수 있습니다.

- **자동 기록:** `지원 페이지로 이동`을 누르면 지원한 것으로 간주되어 이곳에 기록됩니다.
- **내역 삭제:** 실제로 지원하지 않았거나 기록이 필요 없으면 `내역 삭제`로 하나씩, `내역 모두 삭제`로 한 번에 지울 수 있습니다. 삭제해도 외부 사이트에 접수된 실제 지원에는 영향을 주지 않습니다.
