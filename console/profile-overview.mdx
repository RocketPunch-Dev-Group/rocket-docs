로켓펀치에 없는 기업이라면 프로필을 새로 만들 수 있습니다.

## 먼저 확인할 것

이미 등록된 기업을 새로 만들면 프로필이 둘로 나뉩니다. 로켓펀치에서 기업명을 검색해 이미 있는지 확인하세요.

이미 등록되어 있다면 새로 만들지 말고 [관리자 권한 신청하기](/console/permission-request) 를 참고해 권한을 받으세요.

## 계정 준비하기

기업 프로필은 담당자의 로켓펀치 계정에 연결됩니다. 계정이 없다면 먼저 로그인해 계정을 만듭니다.

기업 이름으로 계정을 만들기보다 담당자 본인 계정을 사용하시길 권합니다. 담당자가 바뀌어도 계정을 넘겨줄 필요 없이 새 담당자가 권한만 새로 받으면 됩니다.

계정을 만들 때 정하는 핸들은 자주 바꿀 수 없습니다. 한 번 변경하면 60일이 지나야 다시 바꿀 수 있고, 되돌리는 것은 변경 후 30일 이내에만 가능합니다.

핸들 규칙은 [핸들 · 커리어 설정하기](/account-initialization) 를 참고하세요.

## 기업 프로필 만들기

1. `로켓펀치` \> `기업 서비스` 로 이동합니다.
2. 왼쪽 위 기업 이름을 누르고 `기업 생성` 을 선택합니다.
3. 아래 정보를 입력합니다.
4. `기업 생성` 을 눌러 완료합니다.

### 입력하는 정보

| 항목 | 입력 방법 |
| --- | --- |
| 배경 이미지 | 필수 항목입니다. |
| 프로필 이미지 | 필수 항목입니다. |
| 기업명 | 회사명이나 운영 중인 서비스 이름을 사용합니다. |
| 프로필 URL | 영소문자, 숫자, 하이픈을 최대 30자까지 사용합니다. 하이픈은 맨 앞이나 맨 뒤에 올 수 없고 연속해서 쓸 수도 없습니다. |
| 사업자등록번호 | 선택 항목입니다. |
| 기업 소개 | 최대 300자까지 입력할 수 있습니다. 선택 항목입니다. |
| 산업분야 | 대분류를 고르면 소분류를 선택할 수 있습니다. |
| 기업규모 | 인원 기준으로 고릅니다. |

필수 항목을 모두 채우기 전에는 `기업 생성` 버튼이 활성화되지 않습니다.

## 더 입력할 수 있는 정보

기업을 만들 때는 위 항목만 입력합니다. 대표자, 자본금, 연매출, 고용인원, 누적투자유치, 설립일, 본사 주소, 상세 주소, 위치 설명은 만든 뒤에 `프로필` \> `기업 정보` 에서 추가로 입력합니다.
