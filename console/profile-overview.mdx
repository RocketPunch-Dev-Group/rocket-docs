## 주의사항

이미 등록된 기업을 새로 만들면 프로필이 둘로 나뉩니다. 로켓펀치에서 기업명을 검색해 프로필이 있는지 확인하세요.

| 검색 결과 | 시작 방법 |
| :-- | :-- |
| 기존에 만들어진 기업 프로필이 없습니다 | [기업 프로필 만들기](/console/profile-overview) |
| 기업프로필이 있고, 관리자인 동료가 있습니다 | [팀원 초대하기](/console/permission-invite) |
| 기업프로필은 있는데 관리자가 없습니다 | [관리자 권한 신청하기](/console/permission-request) |

기업 프로필이 이미 생성되어 있지만 기존 관리자의 퇴사, 부서이동 등으로 권한 이전이 불가능하다면 기업 프로필을 새로 생성하지 말고 [관리자 권한 신청하기](/console/permission-request) 를 참고해 권한을 받으세요. 기업 프로필이 여러개가 되면 이용자에게 혼동을 줄 수 있습니다.

## 개인 프로필 준비하기

기업 프로필을 생성하기 위해서는 프로필을 관리할 **담당자의 개인 로켓펀치 계정이 필요**합니다. 로켓펀치 계정이 없다면 기업 프로필을 생성할 수 없습니다. 하나의 로켓펀치 계정으로 여러 기업을 관리할 수 있고, 한 기업을 여러 담당자가 함께 관리할 수도 있습니다. 

<Danger>
  **개인 계정 생성시 기업 이름으로 계정을 만들면 안됩니다.** 관리자 권한을 위해 생성하는 개인 프로필은 관리자 소유의 계정이며, 기업 프로필은 기업 전용 계정입니다. 
</Danger>

프로필 생성 시 설정하는 핸들은 자주 바꿀 수 없습니다. 한 번 변경하면 60일이 지나야 다시 바꿀 수 있고, 되돌리는 것은 변경 후 30일 이내에만 가능합니다. 자세한 내용은 [핸들 · 커리어 설정하기](/account-initialization) 를 참고하세요.

## 기업 프로필 만들기

1. `로켓펀치` \> `기업 서비스` 로 이동합니다.
2. 화면의 안내에 따라 기업 프로필을 생성하고, 이미 관리하고 있는 기업이 있다면 `기업 생성` 을 선택하여 진행합니다.

### 입력하는 정보

| 항목 | 입력 방법 |
| --- | --- |
| 배경 이미지 | 필수 항목입니다. |
| 프로필 이미지 | 필수 항목입니다. |
| 기업명 | 회사명이나 운영 중인 서비스 이름을 사용합니다. |
| 프로필 URL | 영소문자, 숫자, 하이픈을 최대 30자까지 사용합니다. 하이픈은 맨 앞이나 맨 뒤에 올 수 없고 연속해서 쓸 수도 없습니다. |
| 사업자등록번호 | 선택 항목입니다. |
| 기업 소개 | 최대 300자까지 입력할 수 있습니다. 선택 항목입니다. |
| 산업분야 | 대분류를 고르면 소분류를 선택할 수 있습니다. |
| 기업규모 | 인원 기준으로 고릅니다. |

필수 항목을 모두 채우기 전에는 `기업 생성` 버튼이 활성화되지 않습니다.

## 추가 정보 입력하기

대표자, 자본금, 연매출, 고용인원, 누적투자유치, 설립일, 본사 주소, 상세 주소, 위치 설명은 우선 기업 프로필을 생성한 뒤에 `프로필` \> `기업 정보` 에서 추가로 입력합니다. 자세한 내용은 [기업 정보 수정하기](/console/profile-basic) 를 참고하세요.
