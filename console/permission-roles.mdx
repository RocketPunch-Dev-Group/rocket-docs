권한은 기본 권한과 기능별 권한 두 층으로 나뉩니다. `결제 및 권한` \> `권한 관리` 에서 누가 어떤 권한을 갖고 있는지 확인할 수 있습니다.

## 기본 권한

| 기본 권한 | 할 수 있는 일 |
| --- | --- |
| 주소유자 | 기업의 최고 권한을 가집니다. 기업 프로필 삭제와 주소유자 이전을 할 수 있습니다. |
| 소유자 | 멤버를 초대하고 삭제하며, 결제수단과 모든 권한을 관리합니다. |
| 구성원 | 부여받은 기능별 권한 안에서만 접근합니다. |

주소유자는 기업마다 한 명입니다.

## 기능별 권한

구성원에게 주는 권한입니다. 영역마다 `없음` 과 `관리자` 중에서 고릅니다.

| 영역 | 관리자가 할 수 있는 일 |
| --- | --- |
| 소셜 | 프로필을 업데이트하고 글을 쓰며 채팅합니다. |
| 채용 | 채용공고를 만들고 지원자를 조회하고 관리합니다. |
| 이벤트 | 이벤트를 만들고 조회하고 관리합니다. |
| 교육 | 교육과정을 만들고 조회하고 관리합니다. |
| 광고 | 광고를 만들고 결제합니다. |

<Note>
  구성원은 기능별 권한을 한 개 이상 선택해야 합니다. 하나도 고르지 않으면 초대할 수 없습니다.
</Note>

## 개별 항목 권한

항목 하나에만 접근하는 권한입니다. 기능별 권한을 주지 않고도 특정 공고나 이벤트만 맡길 수 있습니다.

- **공고 리뷰어:** 지정된 채용공고의 지원자만 확인하고 전형 상태를 바꿉니다. 다른 공고는 볼 수 없습니다.
- **이벤트 추가 관리자:** 특정 이벤트의 운영만 지원합니다. 이벤트 페이지에는 표시되지 않습니다.

외부 협업자나 현장 스태프에게 최소한의 권한만 주고 싶을 때 활용합니다.

## 내 권한 제거하기

`권한 관리` 아래 `권한 제거` 를 누르면 해당 기업에서 내 권한이 모두 사라지고 탈퇴합니다.

<Warning>
  권한을 제거하면 해당 기업의 콘솔에 더 이상 접근할 수 없습니다. 다시 이용하려면 관리자 권한을 새로 신청해야 합니다.
</Warning>
