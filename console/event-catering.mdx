바로 주문 / 견적 요청

바로 주문: 왼쪽에서 음식 담고 수량 확인 결제하고 이후에는 케이터링 업체랑 소통 가능

견적 요청: 

## 견적 요청하기

품목을 정하기 어렵다면 견적을 먼저 요청합니다.

1. 업체의 `견적 요청` 을 눌러 요청서를 엽니다.
2. 참가 예상 인원, 예산, 연락처, 이메일을 입력합니다.
3. 필요한 요청사항이 있다면 메모에 입력합니다.
4. `견적 요청하기` 를 눌러 제출합니다.

이벤트명과 이벤트 일정은 자동으로 채워지며 요청서에서 고칠 수 없습니다. ~~필수 항목을 모두 채우기 전에는~~ `견적 요청하기 `~~버튼이 활성화되지 않습니다.~~
