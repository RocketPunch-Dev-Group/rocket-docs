`로켓펀치` \> `기업 서비스` \> `교육` \> `교육과정 만들기` 에서 교육과정을 등록할 수 있습니다. 등록한 뒤에도 내용을 수정할 수 있습니다.

## 과정 정보 입력하기

| 항목 | 내용 |
| --- | --- |
| 과정명 | 필수 항목입니다. |
| 한 줄 소개 | 최대 50자. 교육 과정을 간단히 설명합니다. |
| 교육 분야 | 최대 3개까지 선택합니다. |
| 교육 대상 · 교육 유형 · 온오프라인 | 목록에서 각각 선택합니다. |
| 첨부 이미지 | 최대 10개까지 올릴 수 있습니다. 파일당 최대 10MB, 가로 최대 2160px, 세로 최대 8,640px입니다. |
| 과정 설명 | 과정 소개, 모집 일정, 교육 비용, 위치 및 환경, 모집 및 선발절차, 수강 혜택, 참고사항을 작성할 수 있습니다. |

## 상세 정보 입력하기

| 항목 | 내용 |
| --- | --- |
| 교육비 | 수강생이 실제로 내는 본인 부담금을 입력합니다. 국비 지원 등으로 부담금이 없으면 0으로 둡니다. |
| 교육 기간 | 교육이 진행되는 시작일과 종료일입니다. 모집 기간과 다릅니다. |
| 모집 정원 | 명 단위로 입력합니다. |
| NCS | 해당하는 능력단위를 선택합니다. 없으면 `해당없음` 으로 둡니다. |
| 주소 · 상세 주소 | 주소를 검색해서 선택하고, 상세 주소를 입력합니다. |

## 지원 방식 선택하기

| 방식 | 내용 | 조건 |
| --- | --- | --- |
| 외부 페이지 | 신청하기를 누르면 자체 교육 사이트로 이동합니다. `지원 페이지 URL` 에 신청 페이지 주소를 입력합니다. | 현재 이용 가능합니다. |
| 간편 지원 | 로켓펀치에서 신청서와 상태를 관리합니다. | 지원 예정입니다. |

## 모집 기간 설정하기

모집 기간은 한국 표준시(KST)를 기준으로 계산합니다. 신청을 받는 시작일과 마감일을 지정할 수 있고, 상시 모집 설정 시 마감일 없이 계속 모집합니다.
