`로켓펀치` \> `기업 서비스` 에서 이벤트를 열고, 이벤트 상세의 `게스트 및 대기열` 에서 신청 현황을 관리합니다.

## 등록 상태

| 상태 | 설명 |
| --- | --- |
| 대기 중 | 호스트 승인을 기다리는 신청자입니다. |
| 초대됨 | 호스트에게 초대받은 게스트입니다. |
| 승인됨 | 참가가 확정된 게스트입니다. |
| 거절됨 | 참가 신청이 거절된 신청자입니다. |
| 체크인 전 | 참가가 확정되었지만 아직 체크인하지 않은 게스트입니다. |
| 체크인 완료 | 현장에 도착해 입장 처리된 게스트입니다. |
| 불참 | 참가가 확정되었지만 행사에 참석하지 않은 게스트입니다. |
| 취소됨 | 참가를 취소한 게스트입니다. |

티켓 생성 시 `호스트 승인 필요` 를 켜지 않았다면 신청과 동시에 승인됩니다.

## 등록 관리하기

게스트, 티켓 종류, 등록 시간, 등록 상태가 표시됩니다. 대기 중인 신청자를 확인하고 `✓ 버튼` 을 눌러 승인하거나 `X 버튼` 을 눌러 거절할 수 있습니다. 

이름이나 이메일로 검색할 수 있고, 상태로 걸러보거나 신청일 순으로 정렬할 수 있습니다. CSV 파일로 게스트 목록을 내보낼 수도 있습니다. 

참가 현황에서 게스트 상태별 현황을 확인할 수 있습니다. `체크인` 버튼을 누르면 체크인을 시작할 수 있습니다. 자세한 내용은 이벤트 체크인 관리하기 를 확인하세요. 

한정 수량을 설정한 티켓은 남은 수량이 함께 표시됩니다. `티켓 관리` 를 눌러 관리할 수 있습니다.

## 게스트 숨기기

이벤트 상세의 `권한 및 설정` \> `추가 설정` 에서 설정합니다.

- **게스트 숨기기:** 참가 게스트 목록을 호스트만 조회할 수 있도록 숨깁니다.
