`로켓펀치` \> `기업 서비스` 에서 이벤트를 열고, 이벤트 상세의 `게스트 및 대기열` 에서 신청 현황을 관리합니다.

## 등록 상태

| 상태 | 설명 |
| --- | --- |
| 대기 중 | 호스트 승인을 기다리는 신청자입니다. |
| 초대됨 | 호스트에게 초대받은 게스트입니다. |
| 승인됨 | 참가가 확정된 게스트입니다. |
| 거절됨 |  |
| 체크인 전 |  |
| 체크인 완료 | 현장에 도착해 입장 처리된 게스트입니다. |
| 불참 |  |
| 취소됨 |  |

티켓에 `호스트 승인 필요` 를 켜지 않았다면 신청과 동시에 승인됩니다.

## 게스트 확인하기

게스트, 티켓 종류, 등록 시간, 등록 상태가 표시됩니다. 이름이나 이메일로 검색할 수 있고, 상태로 걸러보거나 신청일 순으로 정렬할 수 있습니다.

## 승인하기

`대기 중` 인 신청자를 확인하고 승인합니다.

`위치 비공개` 를 켠 이벤트는 승인된 게스트에게만 위치가 공개됩니다.

## 체크인하기

행사 당일 `체크인` 에서 도착한 게스트를 입장 처리합니다. 자세한 내용은 [이벤트 체크인 관리하기](/console/event-check-in) 를 참고하세요.
