엔터프라이즈 콘솔은 로켓펀치에 등록한 기업이 채용, 브랜딩, 광고를 한곳에서 관리하는 공간입니다. 로켓펀치에서 `기업 서비스` 를 누르면 엔터프라이즈 콘솔로 이동합니다.

## 계정과 기업 프로필

기업 프로필은 담당자의 로켓펀치 계정에 연결됩니다. 담당자 계정으로 로그인하면 권한을 가진 기업의 콘솔에 들어갈 수 있습니다. 한 계정으로 여러 기업을 관리할 수 있고, 한 기업을 여러 담당자가 함께 관리할 수도 있습니다.

## 콘솔 구성

| 영역 | 할 수 있는 일 |
| --- | --- |
| 프로필 | 기업 정보를 관리하고 재직자를 확인합니다. |
| 메시지함 | 사용자가 보낸 메시지를 확인하고 답합니다. |
| 콘텐츠 | 채용공고, 이벤트, 교육과정, 광고를 등록하고 관리합니다. |
| 결제 및 권한 | 요금제와 결제수단을 관리하고 팀원 권한을 설정합니다. |

## 대시보드

콘솔에 들어가면 대시보드가 먼저 열립니다. 현재 요금제와 이용 기간, 활성 공고 수, 관리자 목록, 최근 메시지를 한 화면에서 확인할 수 있습니다.

여러 기업의 권한을 갖고 있다면 왼쪽 위 기업 이름을 눌러 관리할 기업을 바꿉니다.

화면 오른쪽 위 `언어 변경` 에서 콘솔의 표시 언어를 바꿀 수 있습니다.

## 어떻게 시작하나요

먼저 로켓펀치에서 회사 계정을 조회해 보세요. 기업 프로필 존재 여부에 따라 시작하는 방법이 다릅니다.

| 검색 결과 | 시작 방법 |
| --- | --- |
| 회사가 없습니다 | 기업 프로필을 새로 만듭니다. |
| 회사가 있고, 관리자인 동료가 있습니다 | 동료에게 초대를 요청합니다. |
| 회사는 있는데 관리자가 없습니다 | 관리자 권한을 신청합니다. |

<Warning>
  이미 등록된 기업을 새로 만들면 프로필이 둘로 나뉩니다. 만들기 전에 반드시 검색해 확인하세요.
</Warning>
