## 시작하기

기업 프로필을 생성하기 위해서는 프로필을 관리할 담당자의 개인 로켓펀치 계정이 필요합니다. 로켓펀치 계정이 없다면 기업 프로필을 생성할 수 없습니다. 하나의 로켓펀치 계정으로 여러 기업을 관리할 수 있고, 한 기업을 여러 담당자가 함께 관리할 수도 있습니다. 자세한 내용은 [기업 프로필 만들기](/console/profile-overview)를 참고하세요.

먼저 로켓펀치에서 회사 계정을 조회해 보세요. 기업 프로필 존재 여부에 따라 시작하는 방법이 다릅니다.

| 검색 결과 | 시작 방법 |
| --- | --- |
| 기존에 만들어진 기업 프로필이 없습니다 | [기업 프로필 만들기](/console/profile-overview) |
| 기업프로필이 있고, 관리자인 동료가 있습니다 | [팀원 초대하기](/console/permission-invite) |
| 기업프로필은 있는데 관리자가 없습니다 | [관리자 권한 신청하기](/console/permission-request) |

<Warning>
  이미 등록된 기업을 새로 만들면 프로필이 둘로 나뉩니다. 만들기 전에 반드시 검색해 확인하세요.
</Warning>
