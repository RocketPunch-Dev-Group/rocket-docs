엔터프라이즈 콘솔은 기업이 로켓펀치에서 채용, 브랜딩, 광고를 한곳에서 관리하는 공간입니다.

## 콘솔에 들어가려면

콘솔을 이용하려면 기업 프로필의 관리 권한이 필요합니다. 권한이 없으면 메뉴가 보이지 않습니다.

<Tip>
  아직 권한이 없다면 [관리자 권한 신청하기](/console/permission-request) 를 참고해 먼저 권한을 받으세요.
</Tip>

## 콘솔 구성

| 영역 | 할 수 있는 일 |
| --- | --- |
| 프로필 | 기업 정보를 관리하고 재직자를 확인합니다. |
| 메시지함 | 사용자가 보낸 메시지를 확인하고 답합니다. |
| 콘텐츠 | 채용공고, 이벤트, 교육과정, 광고를 등록하고 관리합니다. |
| 결제 및 권한 | 요금제와 결제수단을 관리하고 팀원 권한을 설정합니다. |

## 대시보드

콘솔에 들어가면 대시보드가 먼저 열립니다. 현재 요금제와 이용 기간, 활성 공고 수, 관리자 목록, 최근 메시지를 한 화면에서 확인할 수 있습니다.

여러 기업의 권한을 갖고 있다면 왼쪽 위 기업 이름을 눌러 관리할 기업을 바꿀 수 있습니다.

<Note>
  화면 오른쪽 위 `언어 변경` 에서 콘솔의 표시 언어를 바꿀 수 있습니다.
</Note>
