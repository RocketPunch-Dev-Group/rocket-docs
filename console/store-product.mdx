`로켓펀치` \> `기업 서비스` \> `상점` \> `판매 상품 관리` 에서 판매할 상품을 등록하고 관리합니다.

## 상품 등록하기

`상품 등록` 을 눌러 상품 정보를 입력합니다.

| 항목 | 입력 방법 |
| --- | --- |
| 카테고리 | 같은 카테고리 상품은 목록에 연달아 표시됩니다. 직접 추가할 수 있습니다. |
| 상품 이미지 | 상품명과 함께 보이는 대표 이미지입니다. 정사각형 비율을 권장합니다. |
| 상세 이미지 | 상품을 눌렀을 때 보이는 이미지입니다. 가로 최소 360px이며, 세로로 긴 이미지는 자동으로 잘려 올라가고 상품 페이지에서는 이어진 상태로 보입니다. |
| 상품명 | 최대 100자까지 입력합니다. |
| 상품 설명 | 최대 500자까지 입력합니다. |
| 상품 가격 | \`직접 입력\` 과 \`문의 필요\` 중에서 고릅니다. `문의 필요` 상품은 고객이 담을 수 있지만 결제되지 않고 0원으로 접수되며, 금액을 정한 뒤 결제 요청을 따로 보냅니다. |
| 할인가 | 선택 항목입니다. 입력하면 정가와 할인율이 함께 표시됩니다. |

## 판매 중단하기

상품 목록의 `구매 가능` 스위치를 끄면 고객이 상품을 볼 수 없습니다. 품절이거나 일시적으로 판매를 멈출 때 사용할 수 있고, 삭제한 상품은 되돌릴 수 없습니다.

## 공통 안내 등록하기

상품 페이지에 공통으로 표시되는 안내입니다. `상품 안내`, `주문 안내`, `배송 안내` 세 가지를 각각 켜고 끌 수 있으며, `수정하기` 를 눌러 내용을 입력합니다.

상품 필수 안내사항, 견적 요청 방법, 배송 일시와 방법을 기입해 두면 좋습니다.
