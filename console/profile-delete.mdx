특별한 경우를 제외하고는 기업 프로필을 직접 삭제할 수 없습니다. 아래의 경우에 한해서 신청 폼을 통해 접수하시면 확인 후 처리해 드립니다.

## 삭제할 수 있는 경우

| 항목 | 내용 |
| --- | --- |
| 폐업하였으며 아무도 경력으로 등록하지않은 경우 | 폐업으로 더 이상 사업을 영위하지 않는 경우 삭제가 가능합니다. 단 폐업한 법인이라 하더라도 이전 재직자가 자신의 경력으로 해당 기업체를 등록한 경우 삭제가 어렵습니다. |
| 개인사업자이면서 5인 미만 사업장인 경우 | 개인 거주 주소지 등이 사업자로 등록되어 있어 개인정보 노출의 우려가 있는 경우에 한하여 삭제가 가능합니다. 단 5인 이상 사업장이며 경력 등록자가 있는 경우 마찬가지로 반려될 수 있습니다. |

<Accordion title="기업 프로필을 삭제할 수 없는 이유" icon="lightbulb">
  - 개인정보보호법에서 보호대상인 ‘개인정보’는 “생존하는 자연인”의 정보만을 지칭합니다. 법인·단체 정보(상호, 주소, 대표자 명, 매출 등)는 개인정보가 아닙니다.
  - 행정해석 및 KISA, 법률신문, 서울시 등 다수 정부·공공기관 공식 자료 역시 “대표자 성명, 사업장 주소 등은 영업정보이자 공개대상으로서, 비공개 또는 삭제 요구 시 법적으로 응할 의무가 없다”고 명시되어 있습니다.
  - 다만 “주민등록번호, 개인 주소, 대표자의 개인연락처”처럼 자연인 고유의 식별정보는 예외적 개인정보로 볼 수도 있으나, 단순 공개된 대표자 명·법인 소재지·사업자 정보만으로는 개인정보에 해당하지 않는다는 게 명확합니다.
</Accordion>

## 삭제 신청하기

### 주소유자 권한 획득하기

적격한 담당자의 요청인지 확인하기 위해 기업 프로필의 주소유자 권한을 확인합니다. 주소유자 권한이 없다면 먼저 권한을 획득해야 삭제를 신청할 수 있습니다.

| 경우 | 시작 방법 |
| :-- | :-- |
| 기업프로필의 주소유자인 동료가 있습니다 | [멤버 초대하기](/console/permission-invite) |
| 기업프로필의 관리자가 없습니다 | [기업 프로필 관리 권한 신청하기](/console/permission-request) |

### 증빙 서류 준비하기

주소유자 권한을 취득하였다면 기업에 소속된 담당자임을 확인할 수 있는 서류가 필요합니다. 모든 서류는 **발급일로부터 3개월 이내**의 것이어야 합니다. 재직증명서 준비가 어려운 경우 4대보험 가입내역확인서로 대신할 수 있으며 카카오톡 등에서 간편하게 발급받을 수 있습니다.

| 구분 | 제출할 수 있는 서류 |
| --- | --- |
| 재직 증명 | 재직증명서, 4대보험 가입내역확인서, 재직 여부를 확인할 수 있는 기타 문서<br />\* 폐업한 경우에도 대표 또는 권한이 있음을 증빙할 수 있는 서류를 첨부해야함. |
| 사업자 확인 | 사업자등록증 또는 폐업사실증명원 |

<Warning>
  사업자가 아닌 경우에는 사업자등록증을 첨부하지 않아도 됩니다. 폐업한 기업이라도 대표이거나 권한이 있음을 증명할 수 있는 서류를 첨부하면 신청할 수 있습니다.

  주민등록번호 뒷자리 등 **민감한 개인정보는 반드시 가린 뒤** 제출하세요. 본인임을 확인할 수 없거나 소속이 확인되지 않으면 신청이 반려될 수 있습니다.
</Warning>

### 폼 작성하기

1. 삭제할 기업의 프로필 주소와 본인의 로켓펀치 계정 주소를 확인합니다.
2. [기업 프로필 관리 권한 신청](https://support.rocketpunch.com/company-permission) 폼에 기업명, 기업 프로필 주소, 담당자 직책, 권한을 받을 계정 주소, 증빙 서류, 결과를 받을 이메일을 입력합니다.
3. **메모란에 기업 프로필 삭제를 요청한다고 적은 뒤** 제출합니다.

## 삭제 후 처리

요청이 확인되면 즉시 처리됩니다.

| 항목 | 처리 |
| --- | --- |
| 기업 프로필 | 접근이 차단됩니다. 프로필 주소가 비활성화되고 검색엔진 수집 목록에서도 제외됩니다. |
| 채용공고 | 게재가 중단되어 조회할 수 없게 됩니다. |
| 구독 | 이용 중인 요금제가 중단됩니다. |
| 결제 내역 | 삭제되지 않고 보존됩니다. |
| 재직자 경력 | 사용자가 본인 프로필에 등록한 경력은 그대로 유지됩니다. |

## 검색엔진에서 내리기

삭제 즉시 검색엔진 수집 목록에서 빠지지만, 이미 수집된 내용은 한동안 검색 결과에 남습니다. 검색엔진이 자체 주기로 갱신하기 때문입니다.

즉시 숨기고 싶은 경우 각 검색엔진에 요청할 수 있습니다.

- Google: [Google 검색에서 웹 검색 결과 삭제하기](https://support.google.com/websearch/answer/11080680?hl=ko)
- 네이버: [검색결과 사이트(게시물) 제외 요청](https://help.naver.com/inquiry/input.help?categoryNo=5575&serviceNo=5626&lang=ko)
