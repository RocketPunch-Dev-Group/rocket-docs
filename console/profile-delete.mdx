---
title: "기업 프로필 삭제하기"
---

콘솔에는 기업 프로필을 직접 삭제할 수 없습니다. 신청 폼을 통해 접수하면 확인 후 처리해 드립니다.

## 삭제 신청하기

[기업 프로필 관리 권한 신청](https://support.rocketpunch.com/company-permission) 폼을 사용합니다. 권한 신청과 같은 폼이며, **메모란에 삭제를 요청한다고 적어주세요.**

1. 삭제할 기업의 기업명과 기업 프로필 주소를 입력합니다.
2. 담당자 직책과 본인의 로켓펀치 계정 주소를 입력합니다.
3. 기업 소속을 증명할 서류를 첨부합니다.
4. **메모란에 기업 프로필 삭제를 요청한다고 적습니다.**
5. 결과를 받을 이메일을 입력하고 제출합니다.

증빙 서류는 발급일로부터 3개월 이내의 재직증명서, 4대보험 가입내역확인서 등입니다. 

## 삭제 후 처리

요청이 확인되면 즉시 처리됩니다.

| 항목 | 처리 |
| --- | --- |
| 기업 프로필 | 접근이 차단됩니다. 프로필 주소가 비활성화되고 검색엔진 수집 목록에서도 제외됩니다. |
| 채용공고 | 게재가 중단되어 조회할 수 없게 됩니다. |
| 구독 | 이용 중인 요금제가 중단됩니다. |
| 결제 내역 | 삭제되지 않고 보존됩니다. |
| 재직자 경력 | 사용자가 본인 프로필에 등록한 경력은 그대로 유지됩니다. |

## 기업 관리 권한 제거하기

기업 관리자로 등록된 상태에서는 개인 프로필을 삭제할 수 없습니다. 기업 권한을 먼저 제거해야 계정 삭제가 진행됩니다. 자세한 내용은 [관리자 권한 제거하기](/console/permission-delete) 를 참고하세요.

## 검색엔진에서 내리기

삭제 즉시 검색엔진 수집 목록에서 빠지지만, 이미 수집된 내용은 한동안 검색 결과에 남습니다. 검색엔진이 자체 주기로 갱신하기 때문입니다.

즉시 숨기고 싶은 경우 각 검색엔진에 요청할 수 있습니다.

- Google: [Google 검색에서 웹 검색 결과 삭제하기](https://support.google.com/websearch/answer/11080680?hl=ko)
- 네이버: [검색결과 사이트(게시물) 제외 요청](https://help.naver.com/inquiry/input.help?categoryNo=5575&serviceNo=5626&lang=ko)
