`로켓펀치` \> `기업 서비스` \> `채용` \> `채용공고 만들기` 에서 채용 공고를 등록할 수 있습니다.

## 공고 정보 입력하기

| 항목 | 내용 |
| --- | --- |
| 공고 제목 | 최대 30자. 기업명과 연차를 빼고 직무명만 입력합니다. |
| 공고 부제목 | 최대 50자. 기술 스택, 주요 업무, 키워드를 입력합니다. |
| 직군 · 숙련도 · 고용형태 · 근무방식 | 목록에서 각각 선택합니다. |
| 첨부 이미지(선택) | 최대 10개까지 올릴 수 있습니다. 파일당 최대 10MB, 가로 최대 2160px, 세로 최대 8,640px입니다. |
| 공고 상세 | 팀 소개, 주요 업무, 자격요건, 우대사항, 복지 및 근무환경, 진행절차, 참고사항을 작성할 수 있습니다. |

## 지원 방식 선택하기

채용공고 지원 방식에는 간편지원과 아웃링크 방식이 있습니다.

### 간편 지원하기

지원자가 로켓펀치 내에서 이름, 이메일, 전화번호를 입력하고 이력서를 첨부해 바로 지원하는 방식입니다. 로켓펀치에서 지원서를 받고 상태를 관리할 수 있습니다.

| 항목 | 내용 |
| --- | --- |
| 진행 상태 | 로켓펀치 콘솔 내에서 서류 접수, 서류 합격, 면접 합격, 최종 합격/불합격, 채용 중단 등 원하는 상태로 변경 가능하며, 기업의 판단에 따라 중간 과정을 생략할 수도 있습니다. |
| 알림 | 기업이 채용 진행 상태를 바꾸면 지원자의 이메일로 알림이 발송됩니다. |
| 메시지 | 지원자의 로켓펀치 프로필 채팅으로 연락할 수 있습니다. |
| 서류 보관 | 지원 시 등록한 파일을 바로 열어볼 수 있습니다. |

<Warning>
  28일 동안 상태를 변경하지 않으면 자동으로 절차가 종료되며, 더이상 서류를 조회할 수 없습니다.
</Warning>

#### 간편지원 폼 설정하기

지원자가 제출할 서류를 정합니다.

| 항목 | 내용 |
| --- | --- |
| 이름, 연락처, 이메일 | 필수 수집 항목입니다. 기본으로 제공되며 끌 수 없습니다. |
| 이력서 | 필수 여부와 제출 형식을 선택할 수 있습니다. |
| 파일 첨부 | 포트폴리오, 이력서 및 자기소개서 중 지원자가 제출할 서류를 설정할 수 있습니다. 필수 여부를 선택합니다. |
| 직접 입력 | 지원자가 원하는 서류를 직접 추가할 수 있습니다. |
| 병역 이행 여부/장애 및 보훈 대상 여부 | 필요 시 선택 가능합니다. |

### 지원 페이지로 이동하여 지원하기

지원자가 기업이 지정한 외부 채용 페이지에서 지원하는 방식입니다. 자체 사이트에서 지원 DB를 관리하려는 경우 유용하며, Growth 플랜부터 이용 가능합니다. 자세한 내용은 [요금제 알아보기](/console/plan-overview) 를 참고하세요.

## 게시 기간 설정하기

게시 기간은 한국 표준시(KST)를 기준으로 계산합니다. 시작일과 종료일을 지정할 수 있고, 상시 채용 설정 시 종료일 없이 계속 게시합니다.

## 임시 저장하기

임시 저장을 누르면 `채용공고 목록` \> `임시 저장` 탭에서 다시 열 수 있습니다.

단, `임시저장` 을 누른 뒤 채용공고 목록 화면으로 넘어갈 때까지 페이지를 벗어나면 안됩니다. 이동이 끝나기 전에 페이지에서 벗어나면 임시저장되지 않습니다.
