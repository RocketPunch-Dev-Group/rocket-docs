`로켓펀치` \> `기업 서비스` \> `채용` \> `채용공고 만들기` 에서 채용 공고를 등록할 수 있습니다.

## 공고 정보 입력하기

| 항목 | 내용 |
| --- | --- |
| 공고 제목 | 최대 30자. 기업명과 연차를 빼고 직무명만 입력합니다. |
| 공고 부제목 | 최대 50자. 기술 스택, 주요 업무, 키워드를 입력합니다. |
| 직군 · 숙련도 · 고용형태 · 근무방식 | 목록에서 각각 선택합니다. |
| 첨부 이미지(선택) | 최대 10개까지 올릴 수 있습니다. 파일당 최대 10MB, 가로 최대 2160px, 세로 최대 8,640px입니다. |
| 공고 상세 | 팀 소개, 주요 업무, 자격요건, 우대사항, 복지 및 근무환경, 진행절차, 참고사항을 작성할 수 있습니다. |

## 지원 방식 선택하기

채용공고 지원 방식에는 간편지원과 아웃링크 방식이 있습니다. 

| 방식 | 내용 | 조건 |
| --- | --- | --- |
| 간편지원 | 로켓펀치에서 지원서를 받고 상태를 관리합니다. |  |
| 아웃링크 | 지원하기를 누르면 자체 채용 사이트로 이동합니다. 자체 사이트에서 지원 DB를 관리하려는 경우 유용합니다. |  |

### 간편 지원하기

로켓펀치 내에서 이름, 이메일, 전화번호를 입력하고 이력서를 첨부해 바로 지원합니다. 지원 후 버튼이 `지원 완료`로 바뀌며, 같은 공고에 다시 지원할 수 없습니다.

| 항목 | 내용 |
| --- | --- |
| 진행 상태 | 서류 접수 → 서류 합격 → 면접 합격 → 최종 합격 순으로 바뀝니다. 기업의 판단에 따라 중간 과정이 생략되거나 채용 중단/불합격 판단을 받을 수도 있습니다. |
| 알림 | 채용 진행 상태가 바뀌면 이메일로 알려 드립니다. |
| 기업 연락 | 기업 담당자가 내 로켓펀치 프로필 채팅으로 연락할 수 있습니다. |
| 서류 보관 | 지원 시 등록한 파일은 내 프로필 라이브러리에 자동으로 저장됩니다. |

<Warning>
  기업 담당자가 28일 동안 상태를 변경하지 않으면 자동으로 절차가 종료되며, 기업에서 더이상 서류를 조회할 수 없습니다.
</Warning>

### 지원 페이지로 이동하여 지원하기

기업이 지정한 외부 채용 페이지에서 지원하는 방식입니다. `지원 페이지로 이동`을 누른 뒤, 이동한 사이트의 안내에 따라 지원을 완료합니다.

## 게시 기간 설정하기

게시 기간은 한국 표준시(KST)를 기준으로 계산합니다. 시작일과 종료일을 지정할 수 있고, 상시 채용 설정 시 종료일 없이 계속 게시합니다.

## 임시 저장하기

임시 저장을 누르면 `채용공고 목록` \> `임시 저장` 탭에서 다시 열 수 있습니다.

단, `임시저장` 을 누른 뒤 채용공고 목록 화면으로 넘어갈 때까지 페이지를 벗어나면 안됩니다. 이동이 끝나기 전에 페이지에서 벗어나면 임시저장되지 않습니다.
