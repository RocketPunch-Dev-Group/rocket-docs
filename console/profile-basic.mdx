`프로필` \> `기업 정보` 에서 기업 프로필에 표시될 정보를 관리합니다.

입력란은 평소 잠겨 있습니다. 각 영역의 `수정하기` 를 눌러야 입력할 수 있습니다.

## 이미지 등록하기

| 항목 | 규격 |
| --- | --- |
| 배경 이미지 | 데스크탑 5:1, 모바일 4:1 비율로 표시됩니다. 2000x500px 이상을 권장합니다. |
| 프로필 이미지 | 기업을 대표하는 이미지입니다. |

## 기본 정보 등록하기

- **기업명:** 회사명이나 운영 중인 서비스 이름을 사용합니다. 기업을 찾기 쉬운 이름이 좋습니다.
- **프로필 URL:** 기업 프로필의 주소입니다. `www.rocketpunch.com/companies/` 뒤에 붙을 값을 직접 정합니다.
- **기업 소개:** 최대 300자까지 입력할 수 있습니다.
- **사업자등록번호**

기업 소개와 사업자등록번호는 선택 항목입니다.

## 필수 항목

다음 두 가지는 반드시 선택해야 합니다.

- **산업분야:** 대분류와 소분류를 각각 고릅니다.
- **기업규모:** 인원 기준으로 고릅니다.

입력을 마치면 `저장하기` 를 누릅니다. 되돌리려면 `취소` 를 누릅니다.
