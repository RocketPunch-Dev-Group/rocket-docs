---
title: "기업 정보 수정하기"
---

`로켓펀치` \> `기업 서비스` \> `프로필` \> `기업 정보` 에서 기업 프로필에 표시될 정보를 관리합니다. 수정을 위해서는 각 영역의 `수정하기` 를 눌러야 합니다.

<Warning>
  입력을 마친 후 `저장하기` 를 누르지 않으면 수정 사항이 사라집니다. 수정 사항 입력 후 수정을 취소하려면 `취소` 를 누릅니다.
</Warning>

## 이미지 등록하기

| 항목 | 규격 |
| --- | --- |
| 배경 이미지 | 데스크탑 5:1, 모바일 4:1 비율로 표시됩니다. 2000x500px 이상을 권장합니다. |
| 프로필 이미지 | 기업을 대표하는 이미지입니다. \+ 규격 추가, 파일 형식 |

## 기본 정보 등록하기

| 항목 | 내용 |
| --- | --- |
| 기업명 | 회사명이나 운영 중인 서비스 이름을 사용합니다. 기업을 찾기 쉬운 이름이 좋습니다. |
| 프로필 URL | 기업 프로필의 주소입니다. `www.rocketpunch.com/companies/` 뒤에 붙을 값을 직접 정합니다. |
| 기업 소개 | 최대 300자까지 입력할 수 있습니다. 선택 항목입니다. |
| 사업자등록번호 | 선택 항목입니다. |

## 기업 상세 정보

대표자와 재무 정보, 본사 위치를 등록합니다. 모두 선택 항목입니다.

`기업 상세 정보` 영역의 `수정하기` 를 눌러야 입력란이 열립니다. 누르기 전에는 모든 항목이 잠긴 상태로 보입니다. 입력할 칸이 없어 보인다면 `수정하기` 를 눌렀는지 확인하세요.

| 항목 | 내용 |
| --- | --- |
| 대표자 | 대표자명을 입력합니다. |
| 자본금 | 원 단위로 입력합니다. |
| 연매출 | 원 단위로 입력합니다. |
| 고용인원 | 명 단위로 입력합니다. |
| 누적투자유치 | 원 단위로 입력합니다. |
| 설립일 | 달력에서 고릅니다. |
| 본사 주소 | 검색해서 고릅니다. |
| 상세 주소 | 동, 호수 등을 입력합니다. |
| 위치 설명 | 층이나 출입구 안내처럼 찾아오는 데 도움이 될 정보를 입력합니다. |

입력을 마치면 `저장하기` 를 누릅니다.

## 바로가기

홈페이지, 소셜미디어, 앱 다운로드 주소 등을 기업 프로필에 걸어둘 수 있습니다. 항목마다 **제목과 URL** 을 함께 입력하며, 최대 12개까지 등록할 수 있습니다.

기업 프로필에는 기본으로 4개가 펼쳐진 상태로 보입니다. 5번째부터는 접혀 있고, 방문자가 펼쳐서 볼 수 있습니다. 등록한 항목이 하나도 없으면 이 영역 자체가 프로필에 나타나지 않습니다.

YouTube · Instagram · X · Facebook · Threads · App Store · Google Play의 경우 주소를 입력하면 제목을 따로 적지 않아도 서비스 이름이 자동으로 표시됩니다. 

## 자주 묻는 질문

<AccordionGroup>
  <Accordion title="프로필 URL이 무엇인가요?">
    기업 프로필의 웹 주소입니다. 예를 들어 `rocketpunch` 로 정하면 기업 프로필 주소는 `www.rocketpunch.com/companies/rocketpunch `가 됩니다.

    명함이나 채용 안내에 넣기 좋도록 기억하기 쉬운 값으로 정하는 편이 좋습니다.
  </Accordion>

  <Accordion title="기업명을 어떻게 정해야 하나요?">
    구직자가 검색해서 찾기 쉬운 이름이 좋습니다. 법인명과 서비스명이 다르다면 함께 적는 방법도 있습니다.<br />예를 들어 `비바리퍼블리카(토스)` 처럼 쓸 수 있습니다.
  </Accordion>
</AccordionGroup>
