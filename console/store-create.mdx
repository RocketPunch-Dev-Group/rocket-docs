## 상점 생성하기

`로켓펀치` \> `기업 서비스` \> `상점` \> `상점 홈` 에서 `생성하기` 를 눌러 상점을 생성할 수 있습니다.

### 기본 정보 등록하기

| 항목 | 입력 방법 |
| --- | --- |
| 상점 로고 | 이미지 변경 을 눌러 등록합니다. |
| 상점명 | 최대 50자까지 입력합니다. |
| 사업자등록번호 | 하이픈을 빼고 숫자만 입력합니다. 고객에게 공개되지 않습니다. |
| 사업장 주소 | 검색해서 고릅니다. 고객에게 공개되지 않습니다. |
| 상세 주소 | 동, 호수 등을 입력합니다. |
| 홈페이지 | \`https://\` 를 포함한 주소를 입력합니다. |
| 상점 소개 | 최대 500자까지 입력합니다. |

### 상점 소식 등록하기

새 소식, 공지사항, 지난 행사 포트폴리오를 올려 고객에게 보여줄 수 있습니다. 상점 소식 영역의 `등록하기` 를 눌러 제목과 내용을 작성하고 이미지를 첨부합니다. 제목은 100자, 내용은 1000자까지 입력합니다.

고객은 주문 화면에서 `상점 정보` 를 눌러 담당자 연락처, 홈페이지와 함께 이 소식을 확인합니다.

### 문의 연락처 등록하기

담당자명, 담당자 이메일, 담당자 전화번호를 입력합니다. 담당자 이메일로 고객 문의가 도착하며, 주문접수알림 · 견적요청알림 · 정산안내도 이 주소로 발송됩니다.

### 정산 정보 등록하기

판매 수익금을 받을 계좌를 등록합니다. 은행을 고르고 계좌번호와 예금주명을 입력합니다.
