## 세션 · 연사 등록하기

시간대를 먼저 만들고, 그 안에 세션을 넣는 구조입니다.

1. `세션 및 연사` 에서 `추가하기` 를 눌러 날짜와 시작 시간, 종료 시간을 지정합니다.
2. 만들어진 시간대의 `세션 추가` 를 눌러 세션을 등록합니다.
3. `저장` 을 눌러 반영합니다.

세션이 하나도 없는 시간대는 저장할 때 자동으로 삭제됩니다. 시간대는 시작 시간순으로 자동 정렬되니 서로 겹치지 않게 설정하는 것을 권장합니다.

| 항목 | 입력 방법 |
| --- | --- |
| 세션명 | 최대 300자. 필수 항목입니다. |
| 태그 | 분야, 부스, 홀 등을 입력합니다. 태그를 붙이면 참가자가 태그로 걸러서 볼 수 있습니다. 세션이 많은 행사라면 태그 기준을 미리 정해두는 편이 좋습니다. |
| 세션 소개 | 세션 내용을 설명합니다. |
| 연사 | `연사자 추가` 로 등록합니다. 로켓펀치 프로필로 등록하면 게스트가 연사자의 프로필을 바로 볼 수 있습니다. |
| 썸네일 | 세션을 대표할 이미지를 올립니다. |
| Youtube 링크 | 관련 영상 주소를 입력합니다. |

## 공지 발송하기

`공지 발송` 에서 게스트에게 안내를 보냅니다. 발송한 내역은 공지 목록에 남습니다.

1. `발송 대상 선택` 에서 공지를 받을 게스트를 고릅니다.
2. 발송 시각을 정합니다. 즉시 보내거나 예약할 수 있습니다.
3. 발송 방식을 선택합니다.
4. 제목과 본문을 입력하고 `공지 발송` 을 누릅니다.

공지는 게스트가 **티켓 등록 시 입력한 이메일** 로 발송됩니다. 신청 이후 명단이 바뀌었다면 `발송 대상 새로고침` 을 눌러 최신 상태로 맞추세요.

### 발송 비용

발송 비용의 경우 이메일은 무료, 문자메시지는 건당 40원입니다. 최소 100원 이상 결제해야하며, 100원 이하 결제를 시도하는 경우 최소 금액인 100원이 결제됩니다.

## 추가 설정

- **리마인드 발송:** 이벤트 시작 24시간 전과 1시간 전에 게스트에게 리마인드 메일을 발송합니다. 기본으로 켜져 있습니다.
- **게스트 숨기기:** 참가 게스트 목록을 호스트만 조회할 수 있도록 숨깁니다.

## 위험 영역

아래 작업은 되돌릴 수 없습니다. 신중하게 선택해 주세요.

- **소유권 위임:** 이벤트 소유자를 다른 대상에게 넘깁니다. 위임 후 본인의 권한은 '관리자'로 자동 하향 조정됩니다.
- **이벤트 삭제:** 이벤트를 삭제합니다.
