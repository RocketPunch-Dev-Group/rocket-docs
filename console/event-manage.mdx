`로켓펀치` \> `기업 서비스` \> `이벤트` \> `이벤트 만들기` 에서 이벤트를 생성하고, `이벤트 목록` \> `이벤트 관리` 에서 시간대 별 세션(연사)과 자주 묻는 질문을 등록할 수 있습니다.

## 세션 · 연사 등록하기

시간대를 먼저 만들고, 그 안에 세션을 넣는 구조입니다. 세션마다 장소, 분야, 부스 등의 태그를 등록하면 필터로 모아 볼 수도 있습니다.

1. `세션 및 연사` 에서 `추가하기` 를 눌러 날짜와 시작 시간, 종료 시간을 지정합니다.
2. 만들어진 시간대의 `세션 추가` 를 누릅니다.
3. 러 세션을 등록하고 `저장` 을 눌러 반영합니다.

<Tip>
  시간대는 시작 시간 순으로 자동 정렬되니 서로 겹치지 않게 설정하는 것을 권장합니다.
</Tip>

| 항목 | 입력 방법 |
| --- | --- |
| 세션명 | 최대 300자. 필수 항목입니다. |
| 태그 | 분야, 부스, 홀 등을 입력합니다. 태그를 붙이면 참가자가 태그로 걸러서 볼 수 있습니다. 세션이 많은 행사라면 태그 기준을 미리 정해두는 편이 좋습니다. |
| 세션 소개 | 세션 내용을 설명합니다. |
| 연사 | `연사자 추가` 로 등록합니다. 로켓펀치 프로필로 등록하면 게스트가 연사자의 프로필을 바로 볼 수 있습니다. |
| 썸네일 | 세션을 대표할 이미지를 올립니다. |
| Youtube 링크 | 관련 영상 주소를 입력합니다. |

## 자주 묻는 질문 등록하기

이벤트 개요의 `자주 묻는 질문` 에서 `질문 등록하기` 를 눌러 추가합니다. 카테고리 별로 여러개의 질문과 답변을 등록 할 수 있습니다. 화살표 버튼을 눌러 질문의 순서를 변경할 수 있습니다.

## 위험 영역

아래 작업은 되돌릴 수 없습니다. 신중하게 선택해 주세요.

- **소유권 위임:** 이벤트 소유자를 다른 대상에게 넘깁니다. 위임 후 본인의 권한은 '관리자'로 자동 하향 조정됩니다.
- **이벤트 삭제:** 이벤트를 삭제합니다.
