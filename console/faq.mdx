---
title: "자주 묻는 질문"
---

<AccordionGroup>
  <Accordion title="기업 프로필 관리 권한은 어떻게 받나요?">
    기업 소속을 증명하는 서류를 제출하면 확인 후 권한을 부여합니다.

    신청은 [기업 프로필 관리 권한 신청](https://support.rocketpunch.com/company-permission) 폼에서 합니다. 자세한 내용은 [관리자 권한 신청하기](/console/permission-request) 를 참고하세요.
  </Accordion>

  <Accordion title="담당자가 바뀌었는데 어떻게 하나요?">
    새 담당자가 본인 계정으로 관리 권한을 신청하면 됩니다. 기존 담당자의 계정을 넘겨받을 필요가 없습니다.

    신청할 때 권한을 받을 담당자의 로켓펀치 계정 주소를 입력합니다.
  </Accordion>

  <Accordion title="엔터프라이즈 콘솔은 어디에 있나요?">
    기업 프로필의 관리 권한이 있어야 콘솔에 접근할 수 있습니다. 권한이 없으면 메뉴가 표시되지 않습니다.

    권한을 받은 뒤에도 콘솔이 보이지 않는다면 지원센터로 문의하세요.
  </Accordion>

  <Accordion title="기업 프로필 URL이 무엇인가요?">
    기업 프로필의 웹 주소입니다. `www.rocketpunch.com/companies/` 뒤에 붙는 값으로, 콘솔의 기업 정보에서 직접 정할 수 있습니다.
  </Accordion>

  <Accordion title="고용인원이나 설립일을 수정할 칸이 없어요">
    `기업 상세 정보` 영역의 `수정하기` 를 눌러야 입력란이 열립니다. 누르기 전에는 모든 항목이 잠긴 상태로 보입니다.

    자세한 내용은 [기업 상세 정보 관리하기](/console/profile-detail) 를 참고하세요.
  </Accordion>

  <Accordion title="재직자 목록에서 퇴사자를 빼고 싶어요">
    재직자 목록에는 본인 프로필에 해당 기업을 경력으로 등록한 사용자가 표시됩니다. 사용자가 직접 등록한 경력이므로 기업이 임의로 삭제할 수 없습니다.

    대신 기업 프로필에 노출되지 않도록 숨기거나, 재직 상태와 기간을 바꿀 수 있습니다. 자세한 내용은 [재직자 관리하기](/console/profile-employees) 를 참고하세요.
  </Accordion>

  <Accordion title="기업 프로필을 삭제하고 싶어요">
    기업 프로필 삭제는 지원센터를 통해 접수합니다. 콘솔에서 직접 삭제할 수 없습니다.

    삭제 후 처리는 [기업 프로필 삭제하기](/console/profile-delete) 를 참고하세요.
  </Accordion>

  <Accordion title="계정을 삭제하려는데 안 돼요">
    기업 관리자로 등록된 상태에서는 개인 프로필을 삭제할 수 없습니다.

    `기업 서비스` \> `권한 관리` 에서 `권한 제거` 를 눌러 기업 권한을 먼저 제거한 뒤에 계정 삭제를 진행하세요.

    자세한 내용은 [기업 프로필 삭제하기](/console/profile-delete) 를 참고하세요.
  </Accordion>

  <Accordion title="회사에 관리자가 아무도 없어요">
    전임 담당자가 퇴사했거나 계정에 접근할 수 없어 초대해 줄 사람이 없다면, 증빙 서류를 제출해 권한을 받을 수 있습니다.

    자세한 내용은 [관리자 권한 신청하기](/console/permission-request) 를 참고하세요.
  </Accordion>

  <Accordion title="삭제했는데 검색엔진에 계속 보여요">
    검색엔진에 반영되기까지 시간이 걸립니다. 즉시 숨기고 싶은 경우 각 검색엔진에 요청할 수 있습니다.

    - Google: [Google 검색에서 웹 검색 결과 삭제하기](https://support.google.com/websearch/answer/11080680?hl=ko)
    - 네이버: [검색결과 사이트(게시물) 제외 요청](https://help.naver.com/inquiry/input.help?categoryNo=5575&serviceNo=5626&lang=ko)
  </Accordion>

  <Accordion title="채용공고를 올리는 데 비용이 드나요?">
    간편지원 방식으로 등록하는 공고는 무료입니다. 동시에 게재할 수 있는 개수에도 제한이 없습니다.

    채용이 성사되어도 수수료는 발생하지 않습니다. 지원자를 자체 채용 사이트로 보내는 아웃링크 공고는 Growth 플랜부터 이용할 수 있습니다.
  </Accordion>

  <Accordion title="지원자 정보는 어디서 확인하나요?">
    공고를 열고 `지원자 목록` 에서 확인합니다. 지원자를 누르면 제출한 서류를 열어보거나 내려받을 수 있습니다.

    자세한 내용은 [지원자 관리하기](/console/jobs-applicants) 를 참고하세요.
  </Accordion>

  <Accordion title="Free 플랜은 1년만 사용할 수 있나요?">
    Free 플랜은 기간 제한 없이 계속 이용할 수 있습니다. 대시보드에 표시되는 활성 기간은 현재 플랜의 적용 구간을 나타내는 값입니다.
  </Accordion>

  <Accordion title="결제했는데 요금제가 바뀌지 않아요">
    결제가 완료되었는데도 요금제 화면이 이전 플랜으로 남아 있다면 지원센터로 문의하세요.

    기업명, 결제한 플랜, 결제일을 함께 알려주시면 확인이 빠릅니다.
  </Accordion>

  <Accordion title="연간 결제를 하면 무엇이 다른가요?">
    연간 결제를 선택하면 월간 결제보다 17% 저렴합니다.

    결제한 금액과 같은 금액이 광고 크레딧으로 지급되며, 1년 이내에 철회하면 사용하지 않은 크레딧은 반환됩니다.
  </Accordion>
</AccordionGroup>
