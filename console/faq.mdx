<Accordion title="기업 계정은 따로 만드나요?">
  기업 프로필을 생성하려면 프로필을 관리할 **담당자의 개인 로켓펀치 계정이 필요**합니다. 로켓펀치 계정이 없다면 기업 프로필을 생성할 수 없습니다.

  하나의 로켓펀치 계정으로 여러 기업을 관리할 수 있고, 한 기업을 여러 담당자가 함께 관리할 수도 있습니다.

  이때 **기업 이름으로 개인 계정을 만들면 안 됩니다.** 관리자 권한을 위해 생성하는 개인 프로필은 관리자 소유의 계정이며, 기업 프로필은 기업 전용 계정입니다.

  자세한 내용은 [기업 프로필 만들기](/console/profile-overview) 를 참고하세요.
</Accordion>

<Accordion title="기업 프로필 관리 권한은 어떻게 받나요?">
  권한을 가진 동료가 있다면 초대받는 것이 가장 빠릅니다. [멤버 초대하기](/console/permission-invite) 를 참고하세요.

  초대해 줄 사람이 없다면 기업 소속을 증명하는 서류를 제출해 직접 신청합니다. 신청은 [기업 프로필 관리 권한 신청](https://support.rocketpunch.com/company-permission) 폼에서 합니다. 자세한 내용은 [기업 프로필 관리 권한 신청하기](/console/permission-request)를 참고하세요.
</Accordion>

<Accordion title="전임 담당자가 퇴사해서 기업 프로필에 접근할 수 없어요">
  전임자의 계정을 넘겨받을 필요가 없습니다. 새 담당자가 본인 계정으로 권한을 신청하면 됩니다. 자세한 내용은 [멤버가 없는 기업의 권한 받기](/console/permission-request) 를 참고하세요.
</Accordion>

<Accordion title="권한 신청이 반려됐어요">
  신청 폼의 입력 항목을 잘못 기입하면 신청이 반려될 수 있습니다. 항목에 맞는 형식으로 작성하셨는지 확인해주세요. 또한 증빙 서류는 발급일로부터 3개월 이내의 것이어야 합니다.

  | 항목 | 형식 |
  | --- | --- |
  | 로켓펀치 내 기업 프로필 URL | `www.rocketpunch.com/companies/기업주소` |
  | 권한을 받을 담당자 계정 URL | `www.rocketpunch.com/@핸들` |
</Accordion>

<Accordion title="담당자(주소유자)를 바꾸고 싶어요">
  새 담당자를 멤버로 초대한 뒤 `권한 변경` 창에서 주소유자를 변경할 수 있습니다. 자세한 내용은 [멤버 권한 관리하기](/console/permission-manage) 를 참고하세요.
</Accordion>

<Accordion title="기업 서비스는 어디에 있나요?">
  로켓펀치에서 `기업 서비스` 를 누르면 엔터프라이즈 콘솔로 이동합니다.
</Accordion>

<Accordion title="회사 정보를 어디서 수정하나요?">
  `로켓펀치` \> `기업 서비스` \> `프로필` \> `기업 정보` 에서 수정합니다. 각 영역의 `수정하기` 를 눌러야 입력할 수 있습니다. 자세한 내용은 [기업 정보 수정하기](/console/profile-basic)를 참고하세요.
</Accordion>

<Accordion title="고용인원이나 설립일을 수정할 칸이 없어요">
  `기업 상세 정보` 영역의 `수정하기` 를 눌러야 입력란이 열립니다. 누르기 전에는 모든 항목이 잠긴 상태로 보입니다. 자세한 내용은 [기업 정보 수정하기](/console/profile-basic) 를 참고하세요.
</Accordion>

<Accordion title="기업 프로필에 모르는 사람이 있어요">
  재직자 목록에는 본인 프로필에 해당 기업을 경력으로 등록한 사용자가 표시됩니다. 사용자가 직접 등록한 경력이므로 기업이 임의로 삭제할 수 없습니다. 

  대신 기업 프로필에 노출되지 않도록 숨기거나, 재직 상태와 기간을 바꿀 수 있습니다. 자세한 내용은 [관련 사람 관리하기](/console/profile-employees) 를 참고하세요.
</Accordion>

<Accordion title="무엇이 무료이고 무엇이 유료인가요?">
  플랜마다 제공되는 혜택이 다릅니다. 간편 지원 방식의 채용공고 등록과 이벤트 생성은 무료입니다. 자세한 내용은 [요금제 알아보기](/console/plan-overview)를 참고하세요.
</Accordion>

<Accordion title="채용이 성사되면 비용이 발생하나요?">
  로켓펀치에서는 채용 성사 수수료가 요구되지 않습니다. 자세한 내용은 [요금제 알아보기](/console/plan-overview)를 참고하세요.
</Accordion>

<Accordion title="채용공고는 몇 개까지 게시할 수 있나요?">
  모든 플랜에서 동시에 게재할 수 있는 공고 수에 제한이 없습니다. 간편지원 방식의 채용공고 등록은 무료입니다. 자세한 내용은 [요금제 알아보기](/console/plan-overview)를 참고하세요.
</Accordion>

<Accordion title="결제했는데 요금제가 바뀌지 않아요">
  결제가 완료되었는데도 요금제 화면이 이전 플랜으로 남아 있다면 지원센터로 문의하세요.

  기업명, 결제한 플랜, 결제일을 함께 알려주시면 빠른 확인이 가능합니다.
</Accordion>

<Accordion title="공고를 어디서 등록하나요?">
  `로켓펀치` \> `기업 서비스` \> `채용` \> `채용공고 만들기` 에서 등록합니다. 자세한 내용은 [채용공고 등록하기](/console/jobs-create) 를 참고하세요.
</Accordion>

<Accordion title="등록한 공고가 목록에 안 보여요">
  공고 목록은 상태별 탭으로 나뉩니다. 임시 저장한 공고는 `임시 저장` 탭에, 시작일이 오지 않은 공고는 `모집 예정` 탭에 있습니다. 게시 기간이 지난 공고는 `채용 종료` 탭으로 넘어갑니다.

  `임시 저장` 탭에도 없다면 저장이 완료되지 않은 것입니다. `임시저장` 을 누른 뒤 채용공고 목록 화면으로 넘어가기 전 화면을 이탈한다면 임시 저장에 실패할 수 있습니다.
</Accordion>

<Accordion title="지원자 정보는 어디서 확인하나요?">
  공고를 열고 `지원자 목록` 에서 확인합니다. 지원자를 누르면 제출한 서류를 열어보거나 내려받을 수 있습니다.

  자세한 내용은 [지원자 관리하기](/console/jobs-applicants) 를 참고하세요.
</Accordion>

<Accordion title="기업 프로필을 삭제하고 싶어요">
  기업 프로필 삭제는 특수한 경우에만 가능하며, 신청 폼으로 접수합니다. 자세한 내용은 [기업 프로필 삭제하기](/console/profile-delete) 를 참고하세요.
</Accordion>

<Accordion title="계정을 삭제하려는데 안 돼요">
  기업 멤버로 등록된 상태에서는 개인 프로필을 삭제할 수 없습니다.

  `로켓펀치` \> `기업 서비스` \> `권한 관리` 에서 `권한 제거` 를 눌러 기업 권한을 먼저 제거한 뒤에 계정 삭제를 진행하세요.

  자세한 내용은 [기업 프로필 삭제하기](/console/profile-delete) 를 참고하세요.
</Accordion>

<Accordion title="삭제했는데 검색엔진에 계속 보여요">
  검색엔진에 반영되기까지 시간이 걸립니다. 즉시 숨기고 싶은 경우 각 검색엔진에 요청할 수 있습니다.

  - Google: [Google 검색에서 웹 검색 결과 삭제하기](https://support.google.com/websearch/answer/11080680?hl=ko)
  - 네이버: [검색결과 사이트(게시물) 제외 요청](https://help.naver.com/inquiry/input.help?categoryNo=5575&serviceNo=5626&lang=ko)
</Accordion>

<Accordion title="연간 결제를 하면 무엇이 달라지나요?">
  월간 결제보다 약 17% 저렴하고, 플랜별로 광고 크레딧을 추가로 받습니다. 1년 이내에 철회하면 사용하지 않은 크레딧은 반환됩니다.
</Accordion>

<Accordion title="플랜은 언제든지 변경할 수 있나요?">
  업그레이드는 즉시 적용되고, 다운그레이드는 현재 결제 주기가 끝난 뒤에 적용됩니다.

  자세한 내용은 [요금제 알아보기](/console/plan-overview) 를 참고하세요.
</Accordion>

<Accordion title="Enterprise 플랜은 어떻게 신청하나요?">
  기업별 맞춤 상담을 통해 진행됩니다. 요금제 화면의 `플랜 문의` 를 눌러 상담을 요청하세요.
</Accordion>

<Accordion title="언어 설정">
  `로켓펀치` \> `기업 서비스` 상단 바의 `🌐︎` 를 누르면 언어 목록이 열립니다. 한국어, English, 日本語 중 원하는 언어를 고르면 화면이 바로 바뀝니다.
</Accordion>
