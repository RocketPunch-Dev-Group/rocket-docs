<Accordion title="기업 계정은 따로 만드나요?">
  기업 프로필을 생성하려면 프로필을 관리할 **담당자의 개인 로켓펀치 계정이 필요**합니다. 로켓펀치 계정이 없다면 기업 프로필을 생성할 수 없습니다.

  하나의 로켓펀치 계정으로 여러 기업을 관리할 수 있고, 한 기업을 여러 담당자가 함께 관리할 수도 있습니다.

  이때 **기업 이름으로 개인 계정을 만들면 안 됩니다.** 관리자 권한을 위해 생성하는 개인 프로필은 관리자 소유의 계정이며, 기업 프로필은 기업 전용 계정입니다.

  자세한 내용은 [기업 프로필 만들기](/console/profile-overview) 를 참고하세요.
</Accordion>

<Accordion title="기업 프로필 관리 권한은 어떻게 받나요?">
  권한을 가진 동료가 있다면 초대받는 것이 가장 빠릅니다. [멤버 초대하기](/console/permission-invite) 를 참고하세요.

  초대해 줄 사람이 없다면 기업 소속을 증명하는 서류를 제출해 직접 신청합니다. 신청은 [기업 프로필 관리 권한 신청](https://support.rocketpunch.com/company-permission) 폼에서 합니다. 자세한 내용은 [멤버가 없는 기업의 권한 받기](/console/permission-request) 를 참고하세요.
</Accordion>

<Accordion title="전임 담당자가 퇴사해서 계정에 접근할 수 없어요">
  전임자의 계정을 넘겨받을 필요가 없습니다. 새 담당자가 본인 계정으로 권한을 신청하면 됩니다.

  기업 프로필을 새로 만들지 마세요. 프로필이 둘로 나뉘어 이용자에게 혼동을 줍니다. 자세한 내용은 [멤버가 없는 기업의 권한 받기](/console/permission-request) 를 참고하세요.
</Accordion>

<Accordion title="권한 신청이 반려됐어요">
  신청 폼의 입력 항목을 다시 확인해 주세요. 기업 프로필 주소와 담당자 계정 주소는 형식이 다릅니다.

  | 항목 | 형식 |
  | --- | --- |
  | 로켓펀치 내 기업 프로필 URL | `www.rocketpunch.com/companies/기업주소` |
  | 권한을 받을 담당자 계정 URL | `www.rocketpunch.com/@핸들` |

  증빙 서류는 발급일로부터 3개월 이내의 것이어야 합니다.
</Accordion>

<Accordion title="담당자를 바꾸고 싶어요">
  새 담당자를 멤버로 초대한 뒤 `권한 변경` 창에서 주소유자를 넘깁니다.

  자세한 내용은 [멤버 권한 관리하기](/console/permission-manage) 를 참고하세요.
</Accordion>

<Accordion title="로켓펀치로 채용할 수 있나요?">
  기업 프로필을 만들면 채용공고를 무료로 올릴 수 있습니다. 이벤트와 교육과정도 등록할 수 있고, 광고를 집행할 수도 있습니다.

  시작하는 방법은 [엔터프라이즈 콘솔 시작하기](/console/start-overview) 를 참고하세요.
</Accordion>

<Accordion title="기업 서비스는 어디에 있나요?">
  로켓펀치에서 `기업 서비스` 를 누르면 엔터프라이즈 콘솔로 이동합니다.

  기업 프로필의 관리 권한이 있어야 콘솔에 접근할 수 있습니다. 권한이 없으면 메뉴가 표시되지 않습니다.
</Accordion>

<Accordion title="회사 정보를 어디서 수정하나요?">
  `로켓펀치` \> `기업 서비스` \> `프로필` \> `기업 정보` 에서 수정합니다.

  입력란은 평소 잠겨 있습니다. 각 영역의 `수정하기` 를 눌러야 입력할 수 있습니다.
</Accordion>

<Accordion title="고용인원이나 설립일을 수정할 칸이 없어요">
  `기업 상세 정보` 영역의 `수정하기` 를 눌러야 입력란이 열립니다. 누르기 전에는 모든 항목이 잠긴 상태로 보입니다.

  자세한 내용은 [기업 정보 수정하기](/console/profile-basic) 를 참고하세요.
</Accordion>

<Accordion title="기업 프로필에 모르는 사람이 있어요">
  재직자 목록에는 본인 프로필에 해당 기업을 경력으로 등록한 사용자가 표시됩니다. 사용자가 직접 등록한 경력이므로 기업이 임의로 삭제할 수 없습니다.

  대신 기업 프로필에 노출되지 않도록 숨기거나, 재직 상태와 기간을 바꿀 수 있습니다. 자세한 내용은 [재직자 관리하기](/console/profile-employees) 를 참고하세요.
</Accordion>

<Accordion title="채용이 성사되면 수수료를 내나요?">
  채용 성사 수수료는 모든 플랜에서 0%입니다. 무료 플랜을 이용하더라도 채용 성사 수수료가 요구되지 않습니다.
</Accordion>

<Accordion title="채용공고는 몇 개까지 올릴 수 있나요?">
  모든 플랜에서 동시에 게재할 수 있는 공고 수에 제한이 없습니다. 간편지원 공고는 무료입니다.

  지원자를 자체 채용 사이트로 보내는 아웃링크 공고는 Growth 플랜부터 이용할 수 있습니다.
</Accordion>

<Accordion title="Free 플랜은 1년만 사용할 수 있나요?">
  Free 플랜은 기간 제한 없이 계속 이용할 수 있습니다. 대시보드에 표시되는 활성 기간은 현재 플랜의 적용 구간을 나타내는 값입니다.
</Accordion>

<Accordion title="결제했는데 요금제가 바뀌지 않아요">
  결제가 완료되었는데도 요금제 화면이 이전 플랜으로 남아 있다면 지원센터로 문의하세요.

  기업명, 결제한 플랜, 결제일을 함께 알려주시면 확인이 빠릅니다.
</Accordion>

<Accordion title="공고를 어디서 등록하나요?">
  `로켓펀치` \> `기업 서비스` \> `채용` \> `채용공고 만들기` 에서 등록합니다.

  자세한 내용은 [채용공고 등록하기](/console/jobs-create) 를 참고하세요.
</Accordion>

<Accordion title="등록한 공고가 목록에 안 보여요">
  공고 목록은 상태별 탭으로 나뉩니다. 임시 저장한 공고는 `임시 저장` 탭에, 시작일이 오지 않은 공고는 `모집 예정` 탭에 있습니다. 게시 기간이 지난 공고는 `채용 종료` 탭으로 넘어갑니다.

  `임시 저장` 탭에도 없다면 저장이 완료되지 않은 것입니다. `임시저장` 을 누른 뒤 채용공고 목록 화면으로 넘어갈 때까지 페이지를 벗어나지 마세요.
</Accordion>

<Accordion title="지원자 정보는 어디서 확인하나요?">
  공고를 열고 `지원자 목록` 에서 확인합니다. 지원자를 누르면 제출한 서류를 열어보거나 내려받을 수 있습니다.

  자세한 내용은 [지원자 관리하기](/console/jobs-applicants) 를 참고하세요.
</Accordion>

<Accordion title="기업 프로필을 삭제하고 싶어요">
  기업 프로필 삭제는 신청 폼으로 접수합니다. 콘솔에서 직접 삭제할 수 없습니다.

  삭제 후 처리는 [기업 프로필 삭제하기](/console/profile-delete) 를 참고하세요.
</Accordion>

<Accordion title="계정을 삭제하려는데 안 돼요">
  기업 멤버로 등록된 상태에서는 개인 프로필을 삭제할 수 없습니다.

  `로켓펀치` \> `기업 서비스` \> `권한 관리` 에서 `권한 제거` 를 눌러 기업 권한을 먼저 제거한 뒤에 계정 삭제를 진행하세요.

  자세한 내용은 [기업 프로필 삭제하기](/console/profile-delete) 를 참고하세요.
</Accordion>

<Accordion title="삭제했는데 검색엔진에 계속 보여요">
  검색엔진에 반영되기까지 시간이 걸립니다. 즉시 숨기고 싶은 경우 각 검색엔진에 요청할 수 있습니다.

  - Google: [Google 검색에서 웹 검색 결과 삭제하기](https://support.google.com/websearch/answer/11080680?hl=ko)
  - 네이버: [검색결과 사이트(게시물) 제외 요청](https://help.naver.com/inquiry/input.help?categoryNo=5575&serviceNo=5626&lang=ko)
</Accordion>
