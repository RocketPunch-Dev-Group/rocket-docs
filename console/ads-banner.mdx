## 배너 광고

### 배너 타입 선택하기

먼저 노출 위치를 고릅니다. 선택하면 미리보기가 표시됩니다.

| 타입 | 노출 위치 |
| --- | --- |
| 스탠다드 배너 | 게시물, 프로필, 기업 페이지 등 |
| 홈 배너 | 로켓펀치 접속 시 홈 상단 |

### 소재 준비하기

| 항목 | 규격 |
| --- | --- |
| 메인 텍스트 | 최대 2줄, 40자 |
| 서브 텍스트 | 최대 40자 |
| 이동할 URL | 배너를 누르면 이동할 주소 |
| 배경 미디어 | PNG, JPG, GIF, MP4, MOV 형식, 최대 5MB <br />배경 이미지가 밝아 글자가 잘 보이지 않는다면 `배경 어둡게` 를 켭니다. |
| 로고 | 배경이 없는 SVG 또는 PNG, 최대 5MB. 선택 항목입니다. |

### 광고 기간과 비용 산정

광고 기간은 한 번에 최대 60일까지 설정할 수 있습니다. 비용은 일 단가에 집행 일수를 곱해 계산합니다. 등록 화면 아래에 총 비용이 표시되니 확인한 뒤 `배너 광고 시작하기` 를 누릅니다.
