`로켓펀치` \> `기업 서비스` \> `교육` \> `교육과정 목록` 에서 등록한 과정을 관리합니다.

## 과정 확인하기

과정명이나 과정 소개로 검색할 수 있고 교육 분야 · 교육 대상 · 교육 유형 · 온오프라인으로 걸러볼 수 있습니다.

| 항목 | 내용 |
| --- | --- |
| 과정명 | 등록한 과정 이름과 한 줄 소개가 함께 표시됩니다. |
| 교육 분야 · 교육 방법 | 등록할 때 선택한 값이 표시됩니다. |
| 모집 정원 | 명 단위로 표시됩니다. |
| 모집 시작일 · 모집 마감일 | 신청을 받는 기간입니다. |
| 모집 중 | 스위치로 모집 상태를 바꿉니다. |

## 과정 수정하기

과정을 열면 등록한 내용을 한 화면에서 확인할 수 있습니다. 교육 분야, 지원 유형, 지원 URL, 교육비, NCS, 주소, 모집 기간, 교육 기간이 표시됩니다.

`로켓펀치에서 보기` 를 누르면 참여자에게 보이는 화면을 확인할 수 있습니다.

### 수정 · 삭제하기

과정 상세 오른쪽 위의 `··· 추가 메뉴` 에서 과정을 수정하거나 삭제할 수 있습니다.

`수정하기` 를 누르면 교육과정 만들기 화면으로 넘어가고, 등록한 내용이 자동 입력됩니다.

### 모집 상태 바꾸기

목록의 스위치로 모집 상태를 바꿉니다. 끄면 모집이 종료됩니다. 모집 마감일이 지난 과정은 자동으로 `모집 종료` 로 넘어갑니다.

### 참여자 확인하기

현재는 외부 페이지 방식만 이용할 수 있어 콘솔에 참여자 목록이 표시되지 않습니다. 신청자 정보는 `지원 페이지 URL` 로 등록한 자체 사이트에서 확인합니다.

자세한 내용은 [교육과정 등록하기](/console/edu-create) 를 참고하세요.
