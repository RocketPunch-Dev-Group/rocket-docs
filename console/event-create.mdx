무료 이벤트는 개수 제한 없이 무료로 게재할 수 있습니다.

`콘텐츠` \> `이벤트` \> `이벤트 만들기` 에서 등록합니다.

## 기본 정보 입력하기

| 항목 | 입력 방법 |
| --- | --- |
| 이벤트 배너 | 1200x800px, 3:2 비율을 권장합니다. |
| 이벤트명 | 필수 항목입니다. |
| 이벤트 유형 | 최대 2개까지 선택합니다. |
| 이벤트 주제 | 최대 3개까지 선택합니다. |
| 공개 유형 | 이벤트를 공개할 범위를 정합니다. |
| 이벤트 시작 · 종료 | 날짜와 시간을 각각 지정합니다. |

## 이벤트 설명 작성하기

서식 편집기로 작성하며 마크다운도 지원합니다.

첨부 이미지는 최대 10개까지 올릴 수 있습니다. 파일당 최대 10MB, 가로 최대 2160px, 세로 최대 8,640px입니다.

<Tip>
  첨부한 이미지는 설명 아래에 여백 없이 세로로 이어져 표시됩니다. 포스터를 여러 장으로 나눠 올릴 때 활용하세요.
</Tip>

## 이벤트 위치 설정하기

오프라인, 온라인, 온·오프라인 병행, 위치 미정 중에서 선택합니다.

오프라인이나 병행을 선택하면 주소를 반드시 입력해야 합니다. 상세 주소와 부가 설명은 선택 항목입니다. 부가 설명에는 참고 사항이나 엘리베이터 이용 방법처럼 찾아오는 데 도움이 될 내용을 입력합니다.

`위치 비공개` 를 켜면 참가가 승인된 게스트에게만 위치를 공개합니다.

## 참가 방식 선택하기

| 방식 | 참석 조건 |
| --- | --- |
| 개방 행사 | 등록 없이 누구나 참석할 수 있습니다. |
| 등록 행사 | 무료 또는 유료 티켓을 등록해야 참석할 수 있습니다. |

## 티켓 만들기

등록 행사에는 티켓이 필요합니다. 티켓은 여러 종류를 만들 수 있습니다.

| 종류 | 판매 수수료 |
| --- | --- |
| 무료 티켓 | 없음 |
| 유료 티켓 | Free 플랜 3%, Growth 플랜 이상 0% |

<Note>
  이벤트 게재 자체는 플랜과 무관하게 무료입니다. 수수료는 유료 티켓을 판매할 때만 발생합니다.
</Note>

`티켓명` 은 필수입니다. 나머지는 필요할 때 켭니다.

- **티켓 설명:** 이 티켓으로 무엇을 할 수 있는지 설명합니다.
- **호스트 승인 필요:** 켜면 신청자가 바로 확정되지 않고 대기열에 들어갑니다.
- **한정 수량:** 발행할 티켓 수를 제한합니다.
- **판매 시작일 · 판매 종료일:** 티켓을 구매할 수 있는 기간을 정합니다.

`티켓 추가` 를 누르면 조건이 다른 티켓을 더 만들 수 있습니다.

## 티켓 신청 폼 설정하기

`티켓 폼 설정` 에서 신청자에게 받을 정보를 정합니다.

<Warning>
  이름과 이메일은 항상 수집하며 끌 수 없습니다. 이벤트 공지도 이 이메일로 발송됩니다.
</Warning>

- **전화번호:** 필요할 때 켭니다.
- **재직/재학 인증:** 켜면 신청자가 소속을 인증해야 합니다.
- **추가 입력 항목:** `항목 추가` 로 원하는 질문을 직접 만듭니다.

## 게시하기

작성을 마치면 `이벤트 만들기` 를 누릅니다. 아직 게시하지 않으려면 `임시 저장` 을 누릅니다.
