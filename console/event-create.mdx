첨부 이미지는 최대 10개까지 올릴 수 있습니다. 파일당 최대 10MB, 가로 최대 2160px, 세로 최대 8,640px입니다. 첨부한 이미지는 설명 아래에 여백 없이 세로로 이어져 표시됩니다. 포스터를 여러 장으로 나눠 올릴 때 활용하세요.

## 이벤트 위치 설정하기

오프라인, 온라인, 온·오프라인 병행, 위치 미정 중에서 선택합니다. 오프라인이나 병행을 선택하면 주소를 반드시 입력해야 하며, 부가 설명에는 참고 사항이나 엘리베이터 이용 방법처럼 찾아오는 데 도움이 될 내용을 입력하면 됩니다.

오프라인이나 병행을 선택하면 주소를 반드시 입력해야 하고, `위치 비공개` 를 켜면 참가가 승인된 게스트에게만 상세 주소를 공개할 수 있습니다. 다만 위치 비공개의 경우에도 온라인 이벤트의 링크는 이벤트 시작 1시간 전에는 자동 발송되며, 이벤트 관리 페이지에서 원하는 시간에 참가 대상자들에게 일괄 발송할 수도 있습니다.

## 참가 방식 선택하기

| 방식 | 참석 조건 |
| --- | --- |

## 티켓 생성하기

| 항목 | 내용 |
| --- | --- |
| 티켓명 | 필수 입력 항목입니다. |
| 티켓 설명 | 티켓에 대한 설명을 입력합니다. 줄당 19자씩 최대 2줄 작성 가능합니다. |
| 호스트 승인 필요 | 신청자가 바로 확정되지 않고 대기열에 들어갑니다. 무료, 유료 티켓 여부와 관계 없이 호스트가 승인해야 참여할 수 있습니다. |
| 한정 수량 | 발행할 티켓 수를 제한합니다. |
| 판매 시작일 · 판매 종료일 | 티켓을 구매할 수 있는 기간을 정합니다. |
