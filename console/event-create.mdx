---
title: "이벤트 등록하기"
---

`로켓펀치` \> `기업 서비스` \> `이벤트` \> `이벤트 만들기` 에서 이벤트를 생성할 수 있습니다.

## 기본 정보 입력하기

| 항목 | 입력 방법 |
| --- | --- |
| <u>이벤트 배너</u> | 1200x800px 권장, 3:2 비율 |
| 이벤트명 | 필수 항목입니다. |
| 이벤트 유형 | 최대 2개까지 선택합니다. |
| 이벤트 주제 | 최대 3개까지 선택합니다. |
| 공개 유형 | 이벤트를 공개할 범위를 정합니다. |
| 이벤트 시작 · 종료 | 날짜와 시간을 각각 지정합니다. |

이벤트 유형, 주제 목록 작성

공개 이벤트, 비공개 이벤트 초대 전용 따로 빼서 작성

## 이벤트 설명 작성하기

서식 편집기로 작성하며 마크다운 형식도 지원합니다. 최대 글자수 테스트

첨부 이미지는 최대 10개까지 올릴 수 있습니다. 파일당 최대 10MB, 가로 최대 2160px, 세로 최대 8,640px입니다. 첨부한 이미지는 설명 아래에 여백 없이 세로로 이어져 표시됩니다. 포스터를 여러 장으로 나눠 올릴 때 활용하세요.

## 이벤트 위치 설정하기

오프라인, 온라인, 온·오프라인 병행, 위치 미정 중에서 선택합니다.

오프라인이나 병행을 선택하면 주소를 반드시 입력해야 합니다. 상세 주소와 부가 설명은 선택 항목입니다. 부가 설명에는 참고 사항이나 엘리베이터 이용 방법처럼 찾아오는 데 도움이 될 내용을 입력합니다.

`위치 비공개` 를 켜면 참가가 승인된 게스트에게만 위치를 공개할 수 있고, 온라인 이벤트의 링크는 이벤트 시작 1시간 전에는 자동 발송됩니다. 이벤트 관리 페이지에서 원하는 시간에 참가 대상자들에게 일괄 발송할 수도 있습니다.

비공개하더라도 지역(서울 강남구) 정도는 대략 보임

## 참가 방식 선택하기

| 방식 | 참석 조건 |
| --- | --- |
| 개방 행사 | 등록 없이 누구나 참석할 수 있습니다. |
| 등록 행사 | 무료 또는 유료 티켓을 등록해야 참석할 수 있습니다. |

## 티켓 생성하기

| 항목 | 내용 |
| --- | --- |
| 티켓명 | 필수 입력 항목입니다. |
| 티켓 설명 | 티켓에 대한 설명을 입력합니다. 줄당 19자로 최대 2줄 작성 가능합니다. |
| 호스트 승인 필요 | 신청자가 바로 확정되지 않고 대기열에 들어갑니다. 무료, 유료 티켓 여부와 관계 없이 호스트가 승인해야 참여할 수 있습니다. |
| 한정 수량 | 발행할 티켓 수를 제한합니다. |
| 판매 시작일 · 판매 종료일 | 티켓을 구매할 수 있는 기간을 정합니다. |

`티켓 추가` 를 누르면 조건이 다른 티켓을 더 만들 수 있습니다.

티켓 가격 추가

## 티켓 신청 폼 설정하기

내용 보충 활용 방안(체크박스 등) 약관도 넣을 수 있음.

`티켓 폼 설정` 에서 신청자에게 받을 정보를 정합니다.

| 항목 | 내용 |
| --- | --- |
| 이름, 이메일 | 필수 수집 항목입니다. 이벤트 공지도 해당 이메일로 발송됩니다. |
| 전화번호 | 선택 수집 항목입니다. |
| 추가 입력 항목 | 원하는 질문을 직접 만듭니다. |

## 게시하기

작성을 마치면 `이벤트 만들기` 를 누릅니다. 아직 게시하지 않으려면 `임시 저장` 을 누릅니다.

## 티켓 판매 수수료

| 종류 | 판매 수수료 |
| --- | --- |
| 무료 티켓 | 없음 |
| 유료 티켓 | Free 플랜 3%, Growth 플랜 이상 0% |

티켓 판매 수수료 내용 보완

- 플랫폼 수수료 3%, PG사 결제 수수료 따로 있음 국ㄴ ㅐ해외 다름.

이벤트 게재 자체는 플랜과 무관하게 무료입니다. 수수료는 유료 티켓을 판매할 때만 발생합니다. 자세한 내용은 [요금제 알아보기](/console/plan-overview)를 참고하세요.
