---
title: "게시물 · 댓글 신고하기"
---

부적절한 게시물이나 댓글을 발견하면 신고할 수 있습니다. \[[커뮤니티 가이드라인]([https://www.rocketpunch.com/terms?termType=COMMUNITY)\]을 준수하지 않거나 법적 및 윤리적으로 문제가 있다고 판단되는 것을 신고해 주세요.

1. 게시물 또는 댓글의 더보기 버튼 `⋮` 을 누르고 `게시물 신고 / 댓글 신고`를 선택합니다.
2. 신고 사유를 선택하고 `제출` 을 누릅니다.
   | 신고 사유 | 설명 |
   | --- | --- |
   | 타인에 대한 모욕적 표현 | 욕설이나 비방, 조롱으로 특정 사용자를 깎아내리는 경우입니다. |
   | 인종, 성별, 종교 등에 대한 편견이나 혐오 발언 | 특정 집단이나 사람을 차별하거나 혐오를 조장하는 표현이 담긴 경우입니다. |
   | 불쾌하거나 선정적인 언어나 이미지 포함 | 성적 수치심을 유발하는 언어나 이미지가 포함된 경우입니다. |
   | 자해, 자살 권유나 관련 묘사 | 자해나 극단적 선택을 권유하거나 구체적으로 묘사한 경우입니다. |
   | 범죄 계획 공유나 테러 미화 | 범죄를 모의하거나 테러를 정당화하는 내용이 담긴 경우입니다. |
   | 당사자 동의 없이 신상이나 위치 등 개인정보 노출 | 동의 없이 타인의 실명, 연락처, 위치 등을 공개한 경우입니다. |
   | 동의 없이 타인의 저작물 게시 | 타인의 저작물을 허가 없이 가져와 올린 경우입니다. |
   | 자유 입력(최대 500자) | 위 사유에 해당하지 않는 내용을 500자 이내로 직접 입력합니다. |
3. 신고한 게시물이나 댓글은 내 화면에서 바로 숨겨지고, 접수된 신고는 운영팀의 내부 검토를 거쳐 처리됩니다.

<Note>
  신고는 익명으로 유지되며, 제출 후 더 이상 추천되지 않습니다. 상황이 심각한 경우 현지 기관으로 추가 신고하시기 바랍니다.
</Note>
