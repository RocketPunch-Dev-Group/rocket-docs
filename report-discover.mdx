---
title: "디스커버 신고하기"
---

부적절한 디스커버를 발견하면 신고할 수 있습니다. \[[커뮤니티 가이드라인]([https://www.rocketpunch.com/terms?termType=COMMUNITY)\]을 준수하지 않거나 법적 및 윤리적으로 문제가 있다고 판단되는 디스커버를 신고해 주세요.

1. 디스버커 글의 더보기 버튼 `⋮` 을 누르고 `디스커버 신고`를 선택합니다.
2. 신고 사유를 선택하고 `제출` 을 누릅니다.
   | 신고 항목 | 신고 사유 |
   | --- | --- |
   |  |  |
   |  |  |

3. 신고한 디스커버는 내 화면에서 바로 숨겨지고, 접수된 신고는 운영팀의 내부 검토를 거쳐 처리됩니다.

<Note>
  신고는 익명으로 유지되며, 제출 후 더 이상 추천되지 않습니다. 상황이 심각한 경우 현지 기관으로 추가 신고하시기 바랍니다.
</Note>
