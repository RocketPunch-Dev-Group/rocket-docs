부적절한 디스커버를 발견하면 신고할 수 있습니다. [커뮤니티 가이드라인](https://www.rocketpunch.com/terms?termType=COMMUNITY)을 준수하지 않거나 법적 및 윤리적으로 문제가 있다고 판단되는 디스커버를 신고해 주세요.

1. 디스버커 글의 `더보기 버튼 ⋮` 을 누르고 `디스커버 신고`를 선택합니다.
2. 신고 사유를 선택하고 `제출` 을 누릅니다.
   | 신고 사유 | 설명 |
   | --- | --- |
   | 허위 사실이나 왜곡된 정보 포함 | 확인되지 않은 사실을 단정하거나, 사실관계를 다르게 전달하는 소식입니다. |
   | 실제 내용과 다른 제목이나 요약 | 제목과 요약에서 알린 내용이 원문 기사와 다른 경우입니다. |
   | 불쾌하거나 선정적인 표현 · 이미지 포함 | 폭력적이거나 성적 수치심을 유발하는 표현 · 이미지가 담긴 소식입니다. |
   | 홍보를 목적으로 한 광고성 소식 | 소식으로 보이지만 실제로는 특정 상품이나 서비스를 홍보하는 경우입니다. |
   | 저작권 등 권리를 침해한 소식 | 저작물의 권리자가 출처 표시 없이 쓰였거나, 허용한 범위를 넘어 쓰였다고 판단한 경우입니다. |
   | 자유 입력 (최대 500자) | 위 사유에 해당하지 않는 내용을 500자 이내로 직접 입력합니다. |
3. 접수된 신고는 운영팀의 내부 검토를 거쳐 처리됩니다.

<Note>
  신고는 익명으로 유지되며, 제출 후 더 이상 추천되지 않습니다. 상황이 심각한 경우 현지 기관으로 추가 신고하시기 바랍니다.
</Note>
