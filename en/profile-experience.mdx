## Add your activities

You can add the activities you have taken on for your career, including event participation, awards, certifications, projects, publications, news and media, and patents. Adding activities helps you receive more offers.

| Type | Details | Date | Related Company or Organization | Collaborators |
| --- | --- | --- | --- | --- |
| Participation | Events and conferences you attended | Participation date or start date · end date<br />(long-term events supported) | ✓ | ✓ |
| Awards | Competition or award name | Award date | ✓ | ✓ |
| Certification | Certification name | Acquisition date | - | - |
| Projects | Project name<br />(including fundraising experience) | Start date · end date<br />(can be marked as in progress) | ✓ | ✓ |
| Publication | Paper or book title | Publication date | - | ✓ |
| News / Media | News or media title <br />(including interviews) | Broadcast / publication date | - | - |
| Patents | Patent name · patent registration number | Filing date | ✓ | ✓ |

Every type also lets you enter a description or URL and related skills (up to 5 key skills). For Collaborators, you can mention a Rocketpunch profile to link the person.
