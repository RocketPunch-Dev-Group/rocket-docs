`Rocketpunch` \> `Enterprise Services` \> `Education` \> `Courses` is where you manage the courses you posted.

## Reviewing your courses

You can search by course name and summary, and filter by training field, audience, course type, and online or offline.

| Column | Details |
| --- | --- |
| Course name | Shows the course name you registered along with its one-line summary. |
| Training field · Delivery | Shows the values you selected when posting. |
| Capacity | Shown as a number of people. |
| Enrollment start · closing date | The period during which you accept applications. |
| Enrolling | A switch that changes the enrollment status. |

<Tip>
  If a course you never posted appears on Rocketpunch, it was collected and published through the Ministry of Employment and Labor's KDT OpenAPI. It is not linked to your company profile, so it does not appear in your course list.

  Editing it on the government portal updates it on Rocketpunch automatically. If you want to publish and manage it yourself, post a new one in [Posting a course](/en/console/edu-create).
</Tip>

## Editing a course

Open a course to see everything you registered on a single screen: training field, application method, application URL, tuition, NCS, address, enrollment period, and course period.

Select `View on Rocketpunch` to see what attendees see.

### Editing and deleting

Use the `··· More` menu at the top right of the course to edit or delete it.

Selecting `Edit` opens the create-a-course screen with what you registered filled in.

### Changing the enrollment status

Use the switch in the list to change the enrollment status. Turning it off closes enrollment. A course whose closing date has passed moves to `Enrollment closed` automatically.

### Reviewing applicants

Only the external page method is available right now, so no applicant list appears in the console. You review applicant information on the site you registered in `Application page URL`.

For details, see [Posting a course](/en/console/edu-create).
