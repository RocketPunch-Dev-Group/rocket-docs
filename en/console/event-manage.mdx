Open an event in `Rocketpunch` \> `Enterprise Services` \> `Events` \> `Events` and you can manage its overview, tickets, guests and queue, catering, announcements, and permissions and settings.

## Event overview

Review everything you registered on a single screen. Select `Edit` in each section to change it. Select `Copy event link` to copy the address you share with attendees.

## Adding sessions and speakers

You create a time slot first, then put sessions inside it.

1. In `Sessions and speakers`, select `Add` and set the date, start time, and end time.
2. Select `Add session` on the slot you created to register a session.
3. Select `Save` to apply.

A time slot with no sessions is deleted automatically when you save. Slots are sorted by start time automatically, so it is best to keep them from overlapping.

| Field | How to fill it in |
| --- | --- |
| Session name | Up to 300 characters. Required. |
| Tags | Enter things like the track, booth, or hall. Tags let attendees filter the schedule. For an event with many sessions, it helps to decide your tagging scheme up front. |
| Session description | Describes what the session covers. |
| Speaker | Add them with `Add speaker`. Registering a speaker by their Rocketpunch profile lets guests open that profile directly. |
| Thumbnail | Upload an image to represent the session. |
| YouTube link | Enter the address of a related video. |

## Adding frequently asked questions

In `Frequently asked questions` on the event overview, select `Add question`. You can add several questions and answers per category, and reorder them with the arrow buttons.

## Sending announcements

Use `Announcements` to send information to your guests. Everything you send stays in the announcement list.

1. In `Choose recipients`, pick the guests who receive the announcement.
2. Set when it goes out. You can send immediately or schedule it.
3. Choose how it is sent.
4. Enter a subject and body, then select `Send announcement`.

Announcements go to **the email address each guest entered when registering their ticket**. If your guest list changed after registration, select `Refresh recipients` to bring it up to date.

### Sending costs

Email is free and SMS costs ₩40 per message. A payment has to be at least ₩100; if you try to pay less than that, the minimum ₩100 is charged.

## Additional settings

- **Reminders:** Sends guests a reminder email 24 hours and 1 hour before the event starts. On by default.
- **Hide guests:** Hides the attending guest list so only the host can see it.

## Danger zone

The actions below cannot be undone. Choose carefully.

- **Transfer ownership:** Hands the event over to someone else. After the transfer, your own permission is automatically lowered to "admin".
- **Delete event:** Deletes the event.
