Create your event in `Rocketpunch` \> `Enterprise Services` \> `Events` \> `Create event`, then register sessions (and their speakers) by time slot and add frequently asked questions in `Events` \> `Manage event`.

## Adding sessions and speakers

You create a time slot first, then put sessions inside it. Tagging each session with its venue, track, booth, and the like also lets people filter the schedule.

1. In `Sessions and speakers`, select `Add` to add a time slot.
2. Select add time slot to add more. Slots are sorted by start time automatically, so it is best to keep them from overlapping.
3. Select `Add session` on the slot you created.
4. Enter the session name, tags, session description, speakers, thumbnail, and YouTube link.
   | Field | How to fill it in |
   | --- | --- |
   | Session name | Up to 300 characters. Required. |
   | Tags | Enter things like the track, booth, or hall, then select `{Add tag}` to create the tag. Attendees can filter by tag, which helps at events with many sessions. |
   | Session description | Describes what the session covers. |
   | Speaker | Add them with `Add speaker`. Registering a speaker by their Rocketpunch profile lets guests open that profile directly. |
   | Thumbnail | Upload an image to represent the session. It is displayed at a 16:9 ratio. |
   | YouTube link | Enter the address of a related video. |
5. Select `Save` to apply.

## Adding frequently asked questions

In frequently asked questions, select the `+ button` to add a category, and `Add question` to add several questions and answers per category. Select the `arrow buttons ∧ ∨` to reorder the questions.
