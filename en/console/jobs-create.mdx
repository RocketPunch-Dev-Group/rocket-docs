You can post a job in `Rocketpunch` \> `Enterprise Services` \> `Hiring` \> `Create job posting`.

## Entering the posting details

| Field | Details |
| --- | --- |
| Posting title | Up to 30 characters. Leave out the company name and years of experience, and give the role name only. |
| Posting subtitle | Up to 50 characters. Enter the tech stack, main responsibilities, and keywords. |
| Job category · Seniority · Employment type · Work arrangement | Select each one from its list. |
| Attached images (optional) | Up to 10 images. Each file can be up to 10MB, up to 2,160px wide and 8,640px tall. |
| Posting details | You can write about the team, main responsibilities, requirements, nice-to-haves, benefits and working environment, the hiring process, and anything else worth noting. |

## Choosing how people apply

A job posting uses either Quick Apply or an outlink.

### Quick Apply

The applicant enters their name, email, and phone number on Rocketpunch, attaches a resume, and applies right there. You receive the applications on Rocketpunch and manage their status.

| Item | Details |
| --- | --- |
| Status | In the Rocketpunch console you can set the status to Application received, Passed document screening, Passed interview, Hired, Application not selected, Hiring stopped, and so on. Depending on your decision, steps in the middle can be skipped. |
| Notifications | When you change the hiring status, the applicant is notified by email. |
| Messages | You can contact the applicant through chat on their Rocketpunch profile. |
| Document storage | You can open the files they attached when applying right away. |

<Warning>
  If the status is not changed for 28 days, the process ends automatically and the documents can no longer be viewed.
</Warning>

#### Setting up the Quick Apply form

Decide which documents the applicant submits.

| Field | Details |
| --- | --- |
| Name, phone number, email | Collected in every case. They are included by default and cannot be turned off. |
| Resume | You can choose whether it is required and which format is accepted. |
| File attachments | Choose which documents the applicant submits from portfolio, resume, and cover letter, and whether each is required. |
| Custom field | Add any other document you want the applicant to submit. |
| Military service status / Disability and veteran status | Include these if you need them. |

### Applying through the application page

The applicant applies on the external careers page you designate. This is useful if you manage your application database on your own site, and it is available from the Growth plan up. For details, see [Plans](/en/console/plan-overview).

## Setting the posting period

Posting periods are calculated in Korea Standard Time (KST). You can set a start date and an end date, or turn on always hiring to keep the posting up with no end date.

## Saving a draft

Select save as draft and you can reopen the posting under `Job postings` \> `Drafts`.
