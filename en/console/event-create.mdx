You can create an event in `Rocketpunch` \> `Enterprise Services` \> `Events` \> `Create event`.

## Entering the basics

| Field | Details |
| --- | --- |
| Event banner | 1200x800px resolution, 3:2 ratio |
| Event name | Required. |
| Event type | Pick up to 2. |
| Event topic | Pick up to 3. |
| Visibility | Sets who the event is open to. |
| Event start · end | Set a date and time for each. |

You can attach up to 10 images. Each file can be up to 10MB, up to 2,160px wide and 8,640px tall. Attached images appear stacked vertically below the description with no gap between them, which is useful for a poster split across several files.

## Setting the event location

Choose from offline, online, both, and location to be decided.

If you choose offline or both, an address is required. Address details and extra notes are optional. Use the extra notes for anything that helps people find you, such as which elevator to take.

Turn on `Hide location` to reveal the location only to approved guests. For an online event, the link is sent automatically an hour before the event starts. You can also send it to everyone attending at a time you choose, from the event management page.

## Choosing how people attend

| Method | How people attend |
| --- | --- |
| Open Event | Anyone can attend without registering. |
| Registered Event | Attendees have to register a free or paid ticket. |

## Creating tickets

| Field | Details |
| --- | --- |
| Ticket name | Required. |
| Ticket description | Describes the ticket. Up to 2 lines of 19 characters each. |
| Host approval required | Registrants join a queue instead of being confirmed immediately. Whether the ticket is free or paid, the host has to approve it before they can attend. |
| Limited quantity | Limits how many tickets are issued. |
| Sales start · end date | Sets the window in which the ticket can be purchased. |

Select `Add ticket` to create more tickets with different conditions.

## Publishing

When you are done, select `Create event`. To hold off on publishing, select `Save draft`.
