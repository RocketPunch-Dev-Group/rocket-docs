`Rocketpunch` \> `Enterprise Services` \> `Hiring` \> `Job postings` is where you manage your postings by status.

## Checking a posting's status

You can search by posting title, subtitle, and job category, and filter by job category, seniority, and employment type.

| Tab | Postings shown |
| --- | --- |
| Drafts | Postings you have not published yet |
| Hiring | Postings inside their posting period |
| Scheduled | Postings whose start date has not arrived yet |
| Closed | Postings whose end date has passed |

<Note>
  If a draft is missing from the list, saving the draft did not finish. After you select `Save draft`, wait until the list screen appears. For details, see [Posting a job](/en/console/jobs-create).
</Note>

## Editing a posting

Open the posting and select `Edit posting` to change it on the same screen you used to create it. Select `View on Rocketpunch` to see what applicants see.

### Duplicating and deleting

Use the `··· More` menu at the right of the posting to duplicate or delete it.

Selecting `Duplicate posting` opens the create-a-job screen with the duplicated posting's details filled in. It is useful when you post similar roles repeatedly. Selecting `Duplicate posting` does not publish the posting by itself.

### Setting the posting period

In `Posting period` on the posting, choose one of four options. A posting whose end date has passed moves to `Closed` automatically.

<Warning>
  If the status is not changed for 28 days, the process ends automatically and the documents can no longer be viewed.
</Warning>

| Option | What happens |
| --- | --- |
| Save as draft | Moves the posting back to draft. The posting becomes private and cannot be viewed. |
| Start now | Activates the posting immediately. It appears in the Jobs tab and accepts applications. |
| Schedule | The posting appears in the Jobs tab and accepts applications once the start date arrives. |
| Close | Deactivates the posting immediately. It no longer appears in the Jobs tab and cannot be applied to. |

### Setting reviewers and notification emails

Manage these in `Posting settings` on the individual posting.

| Item | Details |
| --- | --- |
| Reviewer | Can only review the applicants for the posting you assign and change their status. Use it when you want someone to handle a single posting. For what the permission covers, see [Understanding permissions](/en/console/permission-roles). |
| Hiring notification emails | Up to 10 addresses. They are notified whenever a new application arrives. |
