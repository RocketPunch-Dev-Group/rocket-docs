---
title: "Managing event hosts and permissions"
description: "How to set an event's public hosts and additional admins, and how to transfer ownership."
---

Open an event in `Rocketpunch` \> `Enterprise Services` \> `Events` \> `Events`, then set hosts and admins in `Permissions and settings`.

## Public hosts

These are shown as the organizers on the event page. Use `Add host` to add the companies or people hosting it with you.

| Permission | Details |
| --- | --- |
| Event admin | Manages everything about the event, from its overview to its tickets. |
| Check-in allowed | Reviews the guest list and runs check-in. |
| None | Shown as a host on the event page but has no permissions. Use `None` when a co-host should appear by name only. |

## Additional admins

These are **private** admins who help you run the event, for example by handling check-in. They are not shown on the event page, and you add them with `Invite admin`.

| Permission | Details |
| --- | --- |
| Event admin | Manages everything about the event, from its overview to its tickets. |
| Check-in allowed | Reviews the guest list and runs check-in. |

<Tip>
  This is useful when you want to make an outside company the event admin or check-in admin for one specific event, without giving them permissions across your whole company.
</Tip>

## Transferring ownership

In `Permissions and settings` on the event, select `Transfer ownership` under the danger zone to hand the event over to another company or person. After the transfer, your own permission is lowered to "admin", and the action cannot be undone.
