You can post a course in `Rocketpunch` \> `Enterprise Services` \> `Education` \> `Create course`. You can still edit it after posting.

## Entering the course details

| Field | Details |
| --- | --- |
| Course name | Required. |
| One-line summary | Up to 50 characters. Describes the course briefly. |
| Training field | Pick up to 3. |
| Audience · Course type · Online or offline | Select each one from its list. |
| Attached images | Up to 10 images. Each file can be up to 10MB, up to 2,160px wide and 8,640px tall. |
| Course description | You can write about the course, the enrollment schedule, tuition, location and facilities, how people are selected, what students get, and anything else worth noting. |

## Entering the specifics

| Field | Details |
| --- | --- |
| Tuition | Enter the self-payment amount the student actually pays. Leave it at 0 when there is nothing to pay, for example with government funding. |
| Course period | The start and end dates the course runs. This is different from the enrollment period. |
| Capacity | Enter the number of people. |
| NCS | Select the competency units that apply. Leave it as `Not applicable` if none do. |
| Address · Address details | Search for the address and select it, then enter the address details. |

## Choosing how people apply

| Method | Details | Availability |
| --- | --- | --- |
| External page | Selecting apply takes people to your own training site. Enter the address of your application page in `Application page URL`. | Available now. |
| Quick Apply | You manage applications and their status on Rocketpunch. | Coming soon. |

## Setting the enrollment period

Enrollment periods are calculated in Korea Standard Time (KST). You can set a start date and a closing date, or turn on always enrolling to keep taking applications with no closing date.
