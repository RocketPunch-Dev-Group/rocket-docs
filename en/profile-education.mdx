## Add your education

You can add not only schools but also training courses and bootcamps you have completed.

| Item | Details |
| --- | --- |
| Educational Institution | The name of the school or educational institution. Search and select one, or enter it yourself. |
| Type | Choose from High School, Associate Degree, Bachelor's Degree, Master's Degree, Doctoral Degree, or Training Course. |
| Major / Department | Search and select one, or enter it yourself. |
| Status | Choose from Graduated, Enrolled, Course completed, On leave, or Dropped out. |
| Enrollment Period | Select a start date and an end date. |
| Related Skills | You can add up to 5 key skills you learned. |
| Description | Describe your major or the course you completed. You can enter up to 2,000 characters. |
