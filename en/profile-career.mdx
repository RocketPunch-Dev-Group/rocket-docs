## Add your work experience

Adding your work experience makes you visible to other users and increases your chances of receiving new offers.

If you held several roles at one company, you can add each role as a separate entry. Your current position appears first on your profile, and the rest are sorted by start date, most recent first.

| Item | Details |
| :-- | :-- |
| Affiliation | The name of the company or organization. Search and select one, or enter it yourself. |
| Employment Type | Choose from Full-time, Fixed-term, Commissioned, Intern, Freelancer, or Self-employed. |
| Role | Your title or role. |
| Work Period | Select a start date and an end date. If you still work there, you can leave the end date empty. |
| Related Skills | You can add up to 5 key skills you used. |
| Description | Describe the position or the work you handled. You can enter up to 2,000 characters. |
