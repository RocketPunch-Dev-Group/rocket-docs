In `Activity` \> `External Applications`, `Job Postings` and `Education Courses` are listed separately. Rocketpunch cannot see the outcome of applications submitted on external sites, so no status is shown.

- **Recorded automatically:** Selecting `Go to application page` counts as applying, so the posting is recorded here.
- **Delete entries:** If you did not actually apply or you no longer need the record, remove entries one at a time with `Delete`, or all at once with `Clear All History`. Deleting an entry does not affect an application you actually submitted on the external site.

For job postings, see [Applying to job postings](/en/jobs-apply). For courses, see [Applying to a course](/en/edu-apply).

## There is a posting or course in my history that I never applied to

For postings and courses where you apply on an external page, the moment you select `Go to application page` it counts as applying and is recorded automatically. If you did not actually apply, delete that entry; it does not affect an application actually submitted on the external site.
