## What is Chat?

- Talk with other users and with companies.
- Check system notifications sent by Rocketpunch.
- Exchange messages without following the other person.
- Chat is available once you log in.

<Info>
  Chats sent by Rocketpunch are system notifications, so if you want to reach the Rocketpunch support team, use the Support Center.
</Info>

## Types of chat

| Type | Description |
| --- | --- |
| Direct message (1:1) | Talk one-on-one with another user or a company. |
| Group chat | Several people talk together in one chat room. |
| Hiring chat | Talk with a company representative about your application during the hiring process. |
| Open chat | (\*Edit) Content to be added later. |
