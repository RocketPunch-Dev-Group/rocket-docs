## Start a direct message

You can start a direct message (1:1) by clicking the new chat button `＋` in Chat, or by clicking `Send message` on the profile of the person you want to talk to.

There are two ways to start a direct message (1:1).

- Click the new chat button `＋` in Chat to create a conversation.
- Click `Send message` on the profile of the person you want to talk to.

Use the `＋` button in the message box to attach photos, videos, and files. Text and attachments cannot be sent together, and files can be up to 25MB.

## Start a group chat

Several people can talk together in one chat room. In a group chat, you can use the poll feature to ask participants for their opinions and collect the results.

1. On the Chat screen, tap the new chat button `＋`, select several people to talk with, and tap `Next`.
2. Set a name and photo for the chat room, then tap `Create Group` to create the group chat.

## Translate chats automatically

Select the translate button at the top of the chat room and messages are translated into the language you set. The translation language follows the language you selected in `Settings` \> `Other` \> `Language & Region`.

Translated messages show a `Translated` label along with `View Original`. Select `View Original` to see the message before translation.

## Manage conversations

In Chat, tap the `More button ⋮` and click `Leave Chat Room`. Once you leave, the chat room disappears from your screen. It still remains for the other person.

## Found an inappropriate message?

Right-click a chat to report the user. For the reporting steps and how reports are handled, see [Report a chat](/en/report-profile).
