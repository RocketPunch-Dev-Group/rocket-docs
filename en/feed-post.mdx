## Writing a thread

You can write short posts about today's thoughts, insights on work, career questions, and more. You can also attach files such as images, or add emoji and links (URLs).

Note that you cannot select more than one profile — personal or company — when you write.

| Item | Details |
| --- | --- |
| Character limit | Up to 2,000 characters, including spaces. |
| Formatting | Posts are saved as plain text only. Formatting such as bold and italic is not supported. |
| Line breaks | You cannot enter consecutive line breaks. When you publish, only a single blank line is kept, and the first line of a post cannot be empty. |

## What you can attach to a thread

### Images

You can upload up to 10 images per post, up to 100MB in total. JPG, JPEG, PNG, WEBP, and GIF formats are supported.

### Poll

You can attach one poll to a post to collect opinions from other users.

| Item | Details |
| --- | --- |
| Structure | A poll consists of one question and its options. The question and each option can be 1–30 characters, and special characters are allowed. |
| Number of options | Two by default, and you can add up to four. |
| How voting works | Each person can vote for only one option, and multiple selections are not allowed. |
| Voting period | Voting opens as soon as the post goes up, and it closes automatically if the post is deleted. |
| Editing limits | You can edit or delete a poll before you publish the post, but you cannot edit it once the post is published. |

### Link previews

When you enter a link (URL) in the body, a preview card appears with it. Even if you enter several links, only the first one you entered is shown as a card.

### Repost

You can share another post as it is on your own feed. You can add your own text when you repost.

| Item | Details |
| --- | --- |
| Repost limit | You can repost the same post only once. |
| Undo repost | Select the repost button on the original post again to undo it. When you undo, the post you created by reposting is deleted immediately. |
| When the original is deleted or hidden | If the original post you reposted is deleted or hidden, the repost shows "This post is no longer available. / The post has been deleted or hidden." |

#### Reposting a thread

You can add your own text to the original thread when you repost it.

#### Reposting a Discover

The repost carries the title, part of the content, and the thumbnail, and you can add your own text to it.

## Editing and deleting a thread

Select the `More button ⋮` on a thread to edit or delete it. When you edit a thread, you can change the body text, but you cannot change the images.
