---
title: "채용공고 · 교육 신고하기"
---

부적절한 채용공고나 교육을 발견하면 신고할 수 있습니다. \[[커뮤니티 가이드라인]([https://www.rocketpunch.com/terms?termType=COMMUNITY)\]을 준수하지 않거나 법적 및 윤리적으로 문제가 있다고 판단된다면 신고해 주세요.

## 채용공고 신고하기

1. 채용공고 상세의 더보기 버튼 `···` 을 누르고 `신고하기`를 선택합니다.
2. 신고 사유를 선택하고 `제출` 을 누릅니다.
   | 신고 사유 | 설명 |
   | --- | --- |
   | 실제 존재하지 않는 직무나 기업 정보 |  |
   | 성별, 연령 등 부적절한 조건 명시 |  |
   | 과도한 신상 정보 요구 (주민번호 등) |  |
   | 입사지원 시 금전 요구 또는 입금 유도 |  |
   | 채용 외 목적의 상업적 게시물 |  |
   | 자유 입력 (최대 500자) | 기타 |
3. 신고한 채용공고는 내 화면에서 바로 숨겨지고, 접수된 신고는 운영팀의 내부 검토를 거쳐 처리됩니다.

## 교육 신고하기

1. 교육 상세의 더보기 버튼 `···` 을 누르고 `신고하기`를 선택합니다.
2. 신고 사유를 선택하고 `제출` 을 누릅니다.
   | 신고 사유 | 설명 |
   | --- | --- |
   |  |  |
   |  |  |
   |  |  |
   |  |  |
   | 자유 입력 (500자 이상) | 기타 |
3. 신고한 교육은 내 화면에서 바로 숨겨지고, 접수된 신고는 운영팀의 내부 검토를 거쳐 처리됩니다.

<Note>
  신고는 익명으로 유지되며, 제출 후 더 이상 추천되지 않습니다. 상황이 심각한 경우 현지 기관으로 추가 신고하시기 바랍니다.
</Note>
