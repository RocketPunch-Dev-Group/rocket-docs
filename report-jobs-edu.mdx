부적절한 채용공고나 교육을 발견하면 신고할 수 있습니다. [커뮤니티 가이드라인](https://www.rocketpunch.com/terms?termType=COMMUNITY_GUIDELINE) 을 준수하지 않거나 법적 및 윤리적으로 문제가 있다고 판단된다면 신고해 주세요.

## 채용공고 신고하기

1. 채용공고 상세의 `더보기 버튼 ···` 을 누르고 `신고하기`를 선택합니다.
2. 신고 사유를 선택하고 `제출` 을 누릅니다.
   | 신고 사유 | 설명 |
   | --- | --- |
   | 실제 존재하지 않는 직무나 기업 정보 | 채용하지 않는 자리를 올렸거나, 기업명 · 소재지 · 근무 조건이 실제와 다른 경우입니다. |
   | 성별, 연령 등 부적절한 조건 명시 | 직무 수행과 관계없는 조건으로 지원 자격을 제한한 경우입니다. |
   | 과도한 신상 정보 요구 (주민번호 등) | 서류 전형에 필요하지 않은 주민등록번호나 가족 정보 등을 요구하는 경우입니다. |
   | 입사지원 시 금전 요구 또는 입금 유도 | 교육비나 보증금 명목으로 지원자에게 비용을 내도록 안내하는 경우입니다. |
   | 채용 외 목적의 상업적 게시물 | 채용이 아니라 상품이나 서비스를 홍보하려고 올린 공고입니다. |
   | 자유 입력 (최대 500자) | 위 사유에 해당하지 않는 내용을 500자 이내로 직접 입력합니다. |
3. 신고한 채용공고는 내 화면에서 바로 숨겨지고, 접수된 신고는 운영팀의 내부 검토를 거쳐 처리됩니다.

## 교육 신고하기

1. 교육 상세의 `더보기 버튼 ···` 을 누르고 `신고하기`를 선택합니다.
2. 신고 사유를 선택하고 `제출` 을 누릅니다.
   | 신고 사유 | 설명 |
   | --- | --- |
   | 실제와 다른 교육 정보 기재 | 모집하지 않는 과정이거나, 일정 · 비용 · 주관 기관이 안내와 다른 경우입니다. |
   | 성별, 연령 등 부적절한 조건 명시 | 교육 내용과 관계없는 조건으로 지원 자격을 제한한 경우입니다. |
   | 과도한 신상 정보 요구 (주민번호 등) | 수강 신청에 필요하지 않은 주민등록번호나 가족 정보를 요구하는 경우입니다. |
   | 안내된 수강료 외 금전 요구 | 공지된 비용 외에 추가 입금이나 결제를 따로 요구하는 경우입니다. |
   | 종교 · 단체 가입 등 교육 외 활동 권유 | 수업 대신 특정 종교나 단체에 가입하도록 이끌거나, 지인을 데려오도록 요구하는 경우입니다. |
   | 교육 외 목적의 상업적 게시물 | 수강생 모집이 아니라 상품이나 서비스를 홍보하려고 올린 게시물입니다. |
   | 자유 입력 (최대 500자) | 위 사유에 해당하지 않는 내용을 500자 이내로 직접 입력합니다. |
   |  |  |
3. 신고한 교육은 내 화면에서 바로 숨겨지고, 접수된 신고는 운영팀의 내부 검토를 거쳐 처리됩니다.

<Note>
  신고는 익명으로 유지되며, 제출 후 더 이상 추천되지 않습니다. 상황이 심각한 경우 현지 기관으로 추가 신고하시기 바랍니다.
</Note>
